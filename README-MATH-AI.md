# Math Manifold — Math for AI

Quartz 5 site generated one-way from the local `MathAI_Knowledge` authoring vault.

- `quartz.config.yaml` always uses explicit publication.
- CI refuses to deploy notes that are not `canonical` and `publish: true`.
- Third-party PDF files and OCR artifacts are forbidden in `content`.
- Private archive paths are removed during export and rejected by CI.
- `content-manifest.json` records the public path and SHA-256 of every note and asset.
- The `v5` branch is the reproducible GitHub Pages deployment branch.
