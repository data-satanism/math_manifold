# Усреднение Рейнольдса как проекция на инвариантные функции

## Зачем нужен результат

Результат нужен, чтобы отделить доказуемый механизм от правдоподобной эвристики в следующем переносе: Усреднение по группе даёт архитектурно простой способ получить инвариантный выход из произвольного признака. Его условия задают точную границу, внутри которой такое заключение обосновано.

## Формулировка со всеми условиями

Для конечной группы $G$ оператор $Pf(x)=|G|^{-1}\sum_{g\in G}f(g\cdot x)$ линеен, инвариантен, идемпотентен и оставляет каждую инвариантную функцию без изменения. Для компактной группы сумма заменяется интегралом по нормированной мере Хаара.

## Доказательство

1. Линейность следует из линейности суммы.
2. Замена индекса $g\mapsto gh$ показывает $P f(h\cdot x)=P f(x)$.
3. Поскольку $Pf$ уже инвариантна, повторное усреднение не меняет её; для инвариантной $f$ все слагаемые исходно равны.

## Контрпример и граница применимости

Для некомпактной группы нормированная конечная мера Хаара отсутствует; на практике приближение малым набором преобразований не является точной проекцией.

## Вычислительная проверка

Усреднить классификатор по группе диэдра и проверить инвариантность, затем сравнить с усреднением по неполному набору поворотов.

1. **Контроль условий.** Выпишите область действия и кванторы формулировки. Затем объясните переход от первого шага доказательства — «Линейность следует из линейности суммы» — к заключительному — «Поскольку $Pf$ уже инвариантна, повторное усреднение не меняет её; для инвариантной $f$ все слагаемые исходно равны».
2. **Вычислительный контроль.** Усреднить классификатор по группе диэдра и проверить инвариантность, затем сравнить с усреднением по неполному набору поворотов. Сравнивайте также величину, которая фигурирует в доказательстве.
3. **Контроль границы.** Проверьте при одном целенаправленно нарушенном условии: Для некомпактной группы нормированная конечная мера Хаара отсутствует; на практике приближение малым набором преобразований не является точной проекцией. Остальные параметры опыта должны оставаться неизменными.
