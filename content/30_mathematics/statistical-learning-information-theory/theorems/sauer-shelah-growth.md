# Лемма Зауэра—Шелаха о функции роста

## Зачем нужен результат

Результат нужен, чтобы отделить доказуемый механизм от правдоподобной эвристики в следующем переносе: Лемма переводит комбинаторную размерность в выборочную сложность бесконечного класса. Его условия задают точную границу, внутри которой такое заключение обосновано.

## Формулировка со всеми условиями

Пусть непустой бинарный класс $H$ имеет VC-размерность $d<\infty$. Число различных разметок любых $n$ точек не превосходит

$$
\sum_{i=0}^{\min(d,n)}\binom ni.
$$

При $1\le d\le n$ эта сумма не превосходит $(en/d)^d$. При $d=0$ возможна ровно одна разметка: если два классификатора расходятся хотя бы в одной точке, класс разбивает эту точку всеми способами.

## Доказательство

Обозначим через $A$ множество разметок первых $n-1$ точек, продолжимых классом $H$. Пусть $B\subseteq A$ состоит из разметок, допускающих оба значения на последней точке. Полное число разметок равно $|A|+|B|$.

Если $B$ разбивает некоторый набор из $d$ точек, класс $H$ разбивает тот же набор вместе с последней точкой. Поэтому $\operatorname{VC}(B)\le d-1$, а $\operatorname{VC}(A)\le d$. Индукция по $n$ и тождество Паскаля дают биномиальную сумму. При $n=0$ разметка пустого набора одна. Случай $d=0$ разобран в формулировке, а при $d\ge n$ сумма равна $2^n$.

Для второй оценки берём $t=d/n\in(0,1]$. Так как $t^i\ge t^d$ при $i\le d$, получаем

$$
\sum_{i=0}^d\binom ni
\le t^{-d}(1+t)^n
\le \left(\frac{en}{d}\right)^d.
$$

## Контрпример и граница применимости

При бесконечной VC-размерности полиномиального ограничения нет. Лемма не учитывает распределение данных и отступ решения.

## Вычислительная проверка

Для порогов на пяти упорядоченных точках есть шесть разметок, включая пустой и полный положительный класс. Для интервалов можно выбрать любой непустой непрерывный блок, поэтому число разметок равно $1+5\cdot6/2=16$. Это в точности $\binom 50+\binom 51+\binom 52$. Для класса из одной нулевой функции число разметок равно 1 при любом $n$.

## Контроль доказательства и вычислительной проверки

1. **Контроль условий.** Почему разметки с двумя продолжениями имеют размерность не выше $d-1$? На каком шаге появляется последняя точка?
2. **Вычислительный контроль.** Перечислите допустимые интервальные блоки на пяти точках. Укажите три набора точек, для которых одна из разметок не реализуется интервалом.
3. **Контроль границы.** Сравните класс одной константы с классом всех бинарных функций. Для второго класса на любых $n$ попарно различных точках получается $2^n$ разметок.
