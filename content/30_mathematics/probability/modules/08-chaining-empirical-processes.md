## Зачем это нужно

Одна эпсилон-сеть видит множество только в одном масштабе. Сложный класс может быть простым грубо, но очень богатым вблизи отдельных точек. Метод цепочек (chaining) строит последовательность всё более точных приближений и суммирует вклад каждой шкалы.

## 1. Субгауссовские приращения

Процесс $(X_t)_{t\in T}$ имеет субгауссовские приращения, если

$$
\|X_t-X_s\|_{\psi_2}
\le
Kd(t,s).
$$

Это локальное условие: оно контролирует разности, а не абсолютный уровень процесса.

## 2. Цепочка приближений

Выбираются сети $T_k$ масштаба $2^{-k}$ и ближайшие приближения $\pi_k(t)$. Тогда

$$
X_t-X_{t_0}
=
\sum_k
\left(
X_{\pi_k(t)}-X_{\pi_{k-1}(t)}
\right).
$$

На грубых шкалах мало пар, но большие приращения. На тонких шкалах пар много, но приращения малы. [[30_mathematics/probability/theorems/dudley-integral-inequality|Неравенство Дадли]] суммирует этот баланс:

$$
\mathbb E\sup_{t\in T}X_t
\le
CK\int_0^\infty
\sqrt{\log N(T,d,\varepsilon)}
\,d\varepsilon.
$$

## 3. Эмпирический процесс

Для класса функций $\mathcal F$

$$
Z_f
=
\frac1n\sum_{i=1}^n
\left(
f(X_i)-\mathbb Ef(X)
\right).
$$

Нас интересует

$$
\sup_{f\in\mathcal F}|Z_f|,
$$

то есть равномерная ошибка по всему классу, а не ошибка одной заранее фиксированной модели.

## 4. Симметризация

Независимые знаки Радемахера $\varepsilon_i$ дают

$$
\mathbb E\sup_{f\in\mathcal F}|Z_f|
\le
2\,
\mathbb E\sup_{f\in\mathcal F}
\left|
\frac1n\sum_i\varepsilon_if(X_i)
\right|.
$$

После условного фиксирования данных остаётся процесс по простым случайным знакам.

## 5. VC-размерность

VC-размерность класса булевых функций — наибольшее число точек, на котором класс может реализовать все двоичные разметки. Это комбинаторная мера богатства, а не просто число параметров.

Конечная VC-размерность $d$ ограничивает покрытия класса, а затем и равномерное отклонение:

$$
\mathbb E\sup_{f\in\mathcal F}
\left|
\frac1n\sum_i f(X_i)-\mathbb Ef(X)
\right|
\lesssim
\sqrt{\frac dn}.
$$

Точный результат: [[30_mathematics/probability/theorems/vc-uniform-law-large-numbers|равномерный закон больших чисел для VC-класса]].

## 6. Обобщение

Для класса гипотез граница по сложности имеет структуру

$$
\boxed{\text{эмпирическая ошибка}}
+
\boxed{\text{сложность класса}/\sqrt n}
+
\boxed{\text{доверительная поправка}}.
$$

Она не оправдывает выбор класса после просмотра той же контрольной выборки без учёта расширенного пространства решений.

## 7. Общие цепочки

Интеграл Дадли иногда завышает супремум. Общий метод цепочек заменяет фиксированное правило выбора сетей оптимизированной многошкальной структурой $\gamma_2(T,d)$. Для гауссовских процессов теорема о мажорирующей мере делает такую оценку точной с точностью до абсолютных констант.

## 8. Понятный образ

Карту страны нельзя одинаково детализировать на всех уровнях. Сначала нужны континенты, затем города, улицы и дома. Ошибка маршрута складывается из небольших уточнений между соседними масштабами. Одна сверхподробная карта всей страны была бы слишком дорогой.

Это **`analogy`** многошкального покрытия.

## 9. Перенос в ИИ

### Установлено

- Симметризация и сложность Радемахера контролируют равномерное отклонение при независимой выборке.
- Конечная VC-размерность даёт скорость порядка $\sqrt{d/n}$ для булевых классов в ожидании.
- Метрическая энтропия может заменить грубое число моделей для непрерывного класса.

### Аналогия

Многошкальная сложность различает крупные семейства почти одинаковых моделей и действительно разнообразные семейства.

### Исследовательская гипотеза

Локализованная метрическая энтропия вокруг найденного решения может быть полезнее глобальной мощности архитектуры для эмпирического прогноза обобщения.

## 10. Режимы отказа

1. Выборка зависима, а применяется независимая симметризация.
2. Класс строится адаптивно по контрольным данным.
3. Используется число параметров вместо доказанной сложности функции.
4. Метрика покрытия не совпадает с метрикой приращений процесса.

## 11. Эксперимент

```python
import numpy as np

rng = np.random.default_rng(79)
n, d = 2000, 30
X = rng.normal(size=(n, d))
y = (X[:, 0] + 0.4 * X[:, 1] > 0).astype(float)

thresholds = np.linspace(-2, 2, 300)
empirical = np.array([(y[X[:, 0] <= t]).mean() if np.any(X[:, 0] <= t) else 0
                      for t in thresholds])
print("число порогов:", thresholds.size, "объём выборки:", n)
```

Эксперимент должен сравнивать равномерную ошибку с независимой большой выборкой, а не только рисовать обучающую кривую.
