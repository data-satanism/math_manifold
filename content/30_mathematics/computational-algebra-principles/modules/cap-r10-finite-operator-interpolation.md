# Две крайние оценки ограничивают промежуточную норму

Операторные нормы матрицы между произвольными $\ell^p$ и $\ell^q$ могут быть трудны для точного вычисления. Иногда доступны две крайние оценки. Интерполяция позволяет получить промежуточную в логарифмической шкале. Важная координата здесь — обратный показатель $1/p$.

Общая формулировка есть в [[30_mathematics/real-analysis/theorems/riesz-thorin-interpolation|теореме Рисса–Торина]]. Здесь доказательство дано для матриц, включая граничные показатели и проверяемый пример, в котором известны все нормы.

## Теорема для матриц

Пусть $A:\mathbb C^n\to\mathbb C^m$, $1\le p_0,p_1,q_0,q_1\le\infty$, $M_j=\|A\|_{p_j\to q_j}$. Для $0<\theta<1$ положим
$$
\frac1{p_\theta}=\frac{1-\theta}{p_0}+\frac{\theta}{p_1},\qquad
\frac1{q_\theta}=\frac{1-\theta}{q_0}+\frac{\theta}{q_1}
$$
с $1/\infty=0$. Тогда
$$
\|A\|_{p_\theta\to q_\theta}\le M_0^{1-\theta}M_1^\theta.
$$
Если матрица вещественна, такой вывод применим с крайними нормами её комплексного продолжения. Для крайних $p=q=1,\infty$ они совпадают с вещественными нормами, поскольку задаются абсолютными суммами столбцов и строк.

## Откуда берутся обратные показатели

Пусть $\|x\|_{p_\theta}=1$. Для ненулевой координаты зададим
$$
x_i(z)=\frac{x_i}{|x_i|}
\,|x_i|^{\,p_\theta((1-z)/p_0+z/p_1)}.
$$
Нулевые координаты фиксируем нулём. На границе $\Re z=j$ модули равны $|x_i|^{p_\theta/p_j}$, и крайняя норма не выше единицы. При $p_j=\infty$ все ненулевые координаты имеют модуль 1. Если $p_\theta=\infty$, оба крайних показателя бесконечны, и берём постоянный $x(z)=x$.

Так же строим $y(z)$ из единичного вектора двойственной нормы $q_\theta'$, подставляя крайние $q_0',q_1'$. Это допустимо, поскольку $1/q_\theta'=1-1/q_\theta$ интерполируется линейно. Фазы $y$ выбираем для билинейного спаривания. Функция
$$
F(z)=\sum_j y_j(z)(Ax(z))_j
$$
аналитична в полосе, ограничена и на её границах удовлетворяет $|F(j+\mathrm it)|\le M_j$ по неравенству Гёльдера. На $z=\theta$ получаем исходную пару $x,y$.

Для полноты нормируем $F$ множителем $M_0^{z-1}M_1^{-z}$ при положительных $M_j$. Нормированная функция имеет модуль не выше единицы на обеих вертикальных границах. Домножим её на $e^{\eta(z^2-1)}$ при $\eta>0$. На вертикальных сторонах модуль множителя не выше единицы, а на горизонтальных при больших $|\Im z|$ он стремится к нулю. Принцип максимума на прямоугольнике даёт внутреннюю оценку, затем $\eta\to0$. Так получается лемма о трёх прямых в нужной форме. Если один $M_j$ равен нулю, $A=0$.

В итоге $|F(\theta)|\le M_0^{1-\theta}M_1^\theta$. Супремум по $x,y$ возвращает операторную норму. Здесь конечномерность позволяет построить аналитические семейства прямо по координатам.

## Контрольный расчёт и предел экстраполяции

Для $A=u v^\top$, $u=(1,2)^\top$, $v=(3,1,1)^\top$ имеем
$$
\|A\|_{p\to p}=\|u\|_p\|v\|_{p'}.
$$
Гёльдер даёт верхнюю оценку, а равенство достигается на векторе, реализующем двойственную норму $v$. Поэтому при $p=1,2,\infty$ получаем соответственно $9,\sqrt{55},10$. Интерполяция между 1 и $\infty$ даёт $\|A\|_{2\to2}\le\sqrt{90}$. Зазор показывает, что промежуточная оценка может быть существенно выше истинной нормы.

Хорда в координатах $1/p,\log\|A\|_{p\to p}$ ограничивает график на отрезке. Продолжение хорды через точки $p=1,2$ до $1/p=0$ даёт $55/9<10$. Вне отрезка это уже не верхняя оценка. Пример проверяет именно экстраполяцию и не нарушает теорему.

Для произвольной матрицы при $p_0=q_0=1$, $p_1=q_1=\infty$, $\theta=1/2$ получаем
$$
\|A\|_{2\to2}\le
\sqrt{\max_j\sum_i|a_{ij}|\;\max_i\sum_j|a_{ij}|}.
$$
Её можно посчитать по структуре или разреженному представлению. Выбор $\theta$ происходит в шкале обратных показателей, а не по среднему арифметическому $p_0,p_1$.

**Связь с ИИ — established.** Для линейного слоя норма $2\to2$ задаёт максимальное усиление евклидовой ошибки. Две крайние оценки дают проверяемую верхнюю границу без полного SVD. Для композиции слоёв произведение таких границ может быть грубым. Оценка на случайной выборке единичных векторов даёт нижнюю оценку нормы и не заменяет доказанные крайние границы.

## Задачи с решениями

1. Почему для $A=I$ оценка точна при $p=q$? Все нормы $p\to p$ равны единице.
2. Какие показатели между $p_0=1$ и $p_1=4$ даёт $\theta=1/2$? $1/p_\theta=5/8$, то есть $p_\theta=8/5$.
3. Можно ли использовать ту же формулу для нелинейной функции по двум наблюдаемым значениям нормы? Доказательство использует линейный $A$ и аналитическую билинейную форму. Для нелинейной задачи нужны отдельные условия.
4. Почему допустимая верхняя оценка $M_j'$ может заменить точную норму $M_j$? Правая часть монотонна по каждому аргументу. Нижняя оценка по выборке такой замены не допускает.
