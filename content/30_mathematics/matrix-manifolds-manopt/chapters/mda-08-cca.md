# 08. Канонический корреляционный анализ

[К карте курса](30_mathematics/matrix-manifolds-manopt/mda-map)

Канонический корреляционный анализ (CCA) ищет линейные признаки, которые согласованно изменяются в двух наборах измерений одних и тех же объектов. Каждый набор имеет собственную матрицу разброса. После нормировки по этим матрицам задача сводится к сингулярному разложению межблочной матрицы. Эта же конструкция объясняет связь с [Прокрустом](30_mathematics/matrix-manifolds-manopt/chapters/mda-06-procrustes) и [линейным дискриминантным анализом](30_mathematics/matrix-manifolds-manopt/chapters/mda-07-lda).

Для разбора пригодятся [сингулярное разложение](30_mathematics/tyrtyshnikov-video-2026/lectures/tva-04-svd-least-squares), ортогональные проекторы и обобщённая спектральная задача. Нелинейное продолжение через матрицы Грама разобрано в заметке о [ядерной канонической корреляции](30_mathematics/kernel-methods/methods/kernel-canonical-correlation).

## Простыми словами

Представим две таблицы, в которых строки относятся к одним и тем же объектам. В первой таблице могут быть характеристики изображения, во второй — характеристики описания. CCA подбирает по одной линейной комбинации из каждой таблицы, чтобы оценки одних и тех же объектов росли и падали вместе. Следующую пару ищут так, чтобы внутри каждой таблицы новая оценка не коррелировала с предыдущими.

Если сменить единицы измерения одного признака, обычная ковариация может резко измениться. CCA сначала придаёт баллам единичную длину в пространстве наблюдений. Поэтому найденное согласование зависит от угла между баллами. Когда у обеих таблиц достаточно столбцов, их линейные комбинации иногда совпадают на обучающей выборке даже без полезного сигнала на новых объектах.

## 8.1. Введение

Печатная страница 270. В PCA один блок признаков и критерий разброса внутри этого блока. В CCA два или более блоков и критерий согласованности между ними. Порядок строк фиксирует пары наблюдений. Если переставить строки только одного блока, его внутренняя матрица разброса останется прежней, а межблочная матрица, как правило, изменится.

Для обозначений далее $X_1\in\mathbb R^{n\times p_1}$, $X_2\in\mathbb R^{n\times p_2}$ и столбцы обоих блоков центрированы. Запишем $C_{ij}=X_i^\top X_j$ и $y_i=X_i a_i$. При работе с разбросом единичность означает $\|y_i\|=1$. При записи через выборочную ковариацию меняется общий масштаб, но формула корреляции та же.

## 8.2. Классическая постановка и решение CCA

Печатные страницы 270–271. Первая пара максимизирует

$$
\frac{a_1^\top C_{12}a_2}
{\sqrt{(a_1^\top C_{11}a_1)(a_2^\top C_{22}a_2)}}.
$$

Удобно ограничиться $a_i^\top C_{ii} a_i=1$. Если $X_i$ полного столбцового ранга, то $C_{ii}\succ0$. Неравенство $p_i<n$ для центрированных данных необходимо для полной размерности, но коллинеарность может сохранить вырождение и при таком размере.

1. Дифференцирование лагранжиана с половинами множителей при квадратичных ограничениях даёт $C_{12}a_2=\rho C_{11}a_1$ и $C_{21}a_1=\rho C_{22}a_2$. Умножение на соответствующие $a_i^\top$ показывает, что оба множителя равны $\rho=y_1^\top y_2$.
2. Исключая один вектор при ненулевой $\rho$ и обратимых $C_{ii}$, получаем $C_{12}C_{22}^{-1}C_{21}a_1=\rho^2 C_{11}a_1$. Для второго блока формула симметрична по индексам. Практический путь через SVD дан в §8.3.
3. Для последующих пар требуем $a_i^\top C_{ii} A_{i,\rm prev}=0$ с матрицей разброса соответствующего блока. В упорядоченном решении $A_i^\top C_{ii}A_i=I_r$ и $A_1^\top C_{12}A_2=\operatorname{diag}(\rho_1,\ldots,\rho_r)$, $0\le\rho_j\le1$. Нулю равны внедиагональные элементы межблочной матрицы. Это уточняет напечатанные в конце с. 271 полные нули и индекс второго ограничения в начале страницы.

Число положительных корреляций не превышает $\operatorname{rank}C_{12}$. При положительном кратном сингулярном числе один и тот же ортогональный поворот допустим внутри соответствующей группы пар. При нулевом значении выбор направлений в двух ядрах может быть независимым.

![Главный угол между двумя одномерными пространствами оценок меняется вместе с канонической корреляцией.](80_assets/matrix-manifolds-manopt/pca-geometry-v1/mda-08-cca.png)

Векторы $u,v$ единичны. Длина проекции $v$ на $u$ равна $\cos\theta$ в выбранном остром диапазоне. Кадры меняют входные направления в учебной постановке. В многомерном случае косинусы главных углов даёт SVD матрицы $U_1^\top U_2$.

## 8.3. Другие постановки CCA

Печатные страницы 272–273. Отбеливание $C_{ii}=R_i^\top R_i$, $u_i=R_i a_i$ переводит обе области допустимости в единичные сферы. Межблочная матрица становится $M=R_1^{-\top}C_{12}R_2^{-1}$. Для SVD $M=U\Sigma V^\top$ первый максимум равен $\sigma_1(M)$ по неравенству $\langle u_1,M u_2\rangle\le\|Mu_2\|\le\sigma_1$. Достижение даёт соответствующая пара сингулярных векторов. Для нескольких осей берут ведущие столбцы $U_r,V_r$ и возвращают коэффициенты левым умножением на $R_1^{-1},R_2^{-1}$, то есть решением треугольных систем.

В матричной постановке (8.7)–(8.8) максимизируют $\operatorname{tr}(U_r^\top M V_r)$ на произведении многообразий Штифеля. Верхняя граница равна сумме $r$ наибольших сингулярных чисел. Например, симметричная матрица $\bigl(\begin{smallmatrix}0&M\\M^\top&0\end{smallmatrix}\bigr)$ имеет положительные собственные значения $\sigma_j$. Репер $[U_r;V_r]/\sqrt2$ ортонормирован, и его след Рэлея равен исходной цели. Ведущая пара сингулярных реперов достигает границы, полученной по спектру.

Максимум следа определяет подпространства, а упорядоченные канонические пары требуют ещё диагонализации межблочной матрицы. Если $M=\operatorname{diag}(0{,}9,0{,}3)$ и $r=2$, любой одинаковый поворот обоих реперов сохраняет след $1{,}2$. После поворота на $45^\circ$ диагональные величины равны $0{,}6$, а вне диагонали появляется модуль $0{,}3$. Для разреженных весов выравнивать базисы таким поворотом можно лишь после проверки их носителей.

## 8.4. Вырожденные матрицы разброса

Печатная страница 273. Книга рассматривает диагональную регуляризацию и обобщённые обратные. Регуляризованная задача заменяет условия нормировки на $a_i^\top(C_{ii}+\eta_i I)a_i=1$. Тем самым цена больших коэффициентов входит прямо в геометрию, и канонические значения регуляризованной задачи отражают изменённую нормировку. При сравнении моделей можно отдельно измерять обычную корреляцию баллов на отложенных парах.

Для точной вырожденной задачи удобно перейти в пространство наблюдений. Пусть $X_i=U_i\Sigma_i V_i^\top$ — тонкие SVD с положительными сингулярными числами. Допустимые единичные баллы имеют вид $y_i=U_i u_i$, $\|u_i\|=1$. Ищем сингулярные числа $U_1^\top U_2$. Они равны косинусам главных углов между $\operatorname{col}X_1$ и $\operatorname{col}X_2$. К каждому баллу подходит коэффициент минимальной нормы $a_i=V_i\Sigma_i^{-1}u_i$, а добавка из $\ker X_i$ ничего не меняет.

**Проверка на вырожденных данных.** Пусть $z=(1,-1,0)^\top/\sqrt2$, $X_1=[z\ z]$, $X_2=z$. Корреляция равна $1$ для всех пар $a_1=(t,1-t)^\top$, $a_2=1$. Минимальную норму имеет $a_1=(1/2,1/2)^\top$. Если оба центрированных блока целиком натягивают $\mathbf1^\perp$, все их главные углы равны нулю и все $n-1$ выборочных корреляций равны $1$. Общая размерность наблюдений сама может создать такой результат.

## 8.5. Разреженный CCA

Печатные страницы 273–274. Разреженность имеет смысл в исходных координатах, если требуется назвать переменные каждого блока. Плотное отбеливание меняет носитель коэффициентов, как в [§7.3](30_mathematics/matrix-manifolds-manopt/chapters/mda-07-lda#73-разреженные-канонические-переменные). При нескольких компонентах даже явная нормировка и внутриблочная некоррелированность не обязаны сделать межблочную матрицу диагональной. Варианты на основе извлечения и вычитания ранговых вкладов могут менять и внутриблочную ортогональность. Полезно измерять $\|A_i^\top C_{ii}A_i-I\|_F$ и внедиагональную часть $A_1^\top C_{12}A_2$ для конкретного метода.

### 8.5.1. Разреженная обобщённая спектральная задача

Печатные страницы 274–276. В DC-CCA объединяют $a=[a_1;a_2]$ и вводят

$$
S=\begin{pmatrix}0&C_{12}\\C_{21}&0\end{pmatrix},\qquad
D=\operatorname{diag}(C_{11},C_{22}).
$$

Тогда $a^\top Sa=2a_1^\top C_{12}a_2$. Без штрафа при $a^\top Da\le1$ и положительном максимуме две части получают равный квадрат длины $1/2$. Это следует из $2xy\le x^2+y^2$ для длин в двух метриках. С логарифмическим штрафом из (8.9) равное распределение может нарушиться, поэтому обе нормы проверяют отдельно. Матрица $S$ обычно неопределённа, а квадратная полноранговая $C_{12}$ делает её обратимой. Для разложения квадратичной части как разности выпуклых функций нужно лишь, чтобы $S+tI\succeq0$. Вырожденность $D$, если она есть, учитывают отдельно по §8.4.

В штрафуемом матричном разложении (PMD) ищут ранговый вклад $d uv^\top$ с ограничениями на длины и разреженность $u,v$. Для единичных $u,v$ раскрытие квадрата нормы даёт при $u^\top M v\ge0$ оптимальный $d=u^\top M v$. Знак одного вектора можно выбрать так, чтобы это выполнялось. Осталось максимизировать билинейную форму. Замена равенств на выпуклые ограничения $\|u\|,\|v\|\le1$ делает выпуклой область каждого отдельного шага при фиксированном другом блоке. Билинейная цель остаётся совместно невыпуклой. Обычный штраф подталкивает отдельные коэффициенты к нулю, слитый штраф дополнительно сближает соседние коэффициенты при осмысленном порядке признаков.

При применении к $C_{12}$ Witten, Tibshirani и Hastie заменяют $C_{ii}$ единичными матрицами и используют евклидовы ограничения. В (8.14) монография обсуждает вариант с исходными матрицами разброса. Размер первого квадратичного ограничения требует $a_1^\top C_{11}a_1\le1$. Эти версии совпадают по метрике после нормировки только в специальных случаях, например при $C_{ii}=I$. [Witten, Tibshirani и Hastie, §4.2](https://pmc.ncbi.nlm.nih.gov/articles/PMC2697346/)

**Исследовательский вопрос книги.** Можно ли ускорить попеременные шаги PMD методами на основе бидиагонализации Ланцоша, сохранив ограничения на носители? Обычный алгоритм Ланцоша этих ограничений не учитывает.

### 8.5.2. Разреженный CCA через наименьшие квадраты

Печатная страница 276. При единичных баллах максимизация скалярного произведения эквивалентна минимизации расстояния $\|X_1a_1-X_2a_2\|^2$. Если один балл фиксирован, другой можно искать регрессией по его блоку. Lykou и Whittaker добавляют ограничение LASSO и фиксируют знаки коэффициентов относительно исходного решения. Тогда при соответствующих выпуклых ограничениях на коэффициенты очередной регрессионный шаг сводится к квадратичному программированию. Буквальное сохранение равенства $a_i^\top C_{ii}a_i=1$ внутри подзадачи не даёт выпуклого множества. Нормировку балла и предыдущие линейные условия ортогональности следует учитывать явно. При повторной нормировке по выборочному разбросу нужно заново проверить допустимость $\ell_1$-бюджета. [Lykou и Whittaker, Sparse CCA using a Lasso with positivity constraints](https://doi.org/10.1016/j.csda.2009.08.002)

## 8.6. Связь CCA с LDA и PLS

Печатная страница 277. Три постановки различаются способом нормировки. Прокруст из §6.2 может совмещать уже заданные евклидовы реперы, CCA выбирает новые единичные баллы в обоих блоках, а LDA при сравнении с классами использует полный или внутриклассовый разброс.

### 8.6.1. CCA и LDA

Печатная страница 277. Вторым блоком возьмём центрированную матрицу индикаторов $JG$. Её столбцовое пространство — контрасты классов. Проектор на него равен $P_B=H-\mathbf1\mathbf1^\top/n$ из §7.1. Для фиксированного единичного балла $y=X_Ta$ наилучший балл классов направлен по $P_By$, если эта проекция ненулевая. Квадрат максимальной корреляции равен

$$
\frac{\|P_B X_T a\|^2}{\|X_T a\|^2}
=\frac{a^\top B a}{a^\top Ta}.
$$

Таким образом, $\rho_j^2=\mu_j$ в нормировке LDA по $T$. При $W\succ0$ получаем $\lambda_j=\rho_j^2/(1-\rho_j^2)$ в нормировке по $W$. Матрица $JG$ имеет ранг $g-1$, поскольку сумма её столбцов равна нулю, поэтому обращать весь разброс индикаторов нельзя. Достаточно ортонормированного базиса контрастов или псевдообратной.

### 8.6.2. CCA и частичные наименьшие квадраты

Печатные страницы 277–279. В симметричной постановке частичных наименьших квадратов (PLS) максимизируют $a_1^\top C_{12}a_2$ при $a_i^\top a_i=1$. В CCA знаменатели измеряют разброс полученных баллов, а в PLS длину коэффициентов. Для этой версии PLS нужна SVD самой $C_{12}$, поэтому вырождение $C_{ii}$ не препятствует вычислению первой пары. Если обе $C_{ii}$ пропорциональны единице, направления первых пар CCA и PLS совпадают.

**Ручная проверка.** Пусть $C_{11}=C_{22}=\operatorname{diag}(100,1)$, $C_{12}=\operatorname{diag}(20,0{,}9)$. PLS выбирает первую ось с перекрёстным произведением $20$. CCA сравнивает корреляции $0{,}2$ и $0{,}9$ и выбирает вторую ось. Раскладывание (8.16)–(8.18) объясняет альтернативный критерий PLS: к невязке между проекциями прибавляют ошибки реконструкции обоих блоков, и их квадраты поглощают члены $\|X_iA_i\|_F^2$. Остаются константа и $-2\operatorname{tr}(A_1^\top C_{12}A_2)$.

Регрессионный PLS учитывает различие между предикторами $X$ и откликом $Y$. Для одного отклика $y$ первый вес пропорционален $X^\top y$, если оно ненулевое. Если второй евклидово ортогональный вес искать на той же линейной цели, её градиент уже параллелен первому весу, и цель на дополнении тождественно нулевая. Для нескольких компонент требуется правило удаления извлечённой вариации. В варианте на основе баллов $t=Xa$ можно обновить $X\leftarrow X-t(t^\top X)/(t^\top t)$ и согласованно обработать отклик по выбранной схеме PLS. Эта проекция действует в пространстве наблюдений. Формула $AA^\top X$ в печатном тексте смешивает размеры, если $A$ содержит веса в пространстве признаков.

## 8.7. Более двух блоков признаков

Печатные страницы 279–280. Когда блоков три и больше, можно согласовывать все пары, оценивать единый целевой репер или выделять общую часть реконструкции. Эти цели совпадают лишь при дополнительных условиях. Номера строк продолжают задавать соответствия объектов во всех блоках.

### 8.7.1. Обобщения CCA

Печатные страницы 280–282. Для единичных $y_i=X_i a_i$ критерий SUMCOR максимизирует $\sum_{i<j}y_i^\top y_j$. SABSCOR суммирует модули, SSQCOR — квадраты. При двух блоках выбор знака делает оптимизаторы эквивалентными с точностью до знака. Для трёх единичных осей под углами $120^\circ$ попарные произведения равны $-1/2$. Смена знака одной оси даёт два значения $1/2$ и одно $-1/2$, поэтому SUMCOR достигает $1/2$, а SABSCOR равен $3/2$. Нельзя независимо выбрать знак для каждой пары одной и той же тройки.

В постановке Кэрролла ищут $Y^\top Y=I_r$, минимизируя $\sum_i\|Y-X_i A_i\|_F^2$. Квадраты нужны для спектрального вывода к (8.21). При фиксированном $Y$ наилучшая проекция $X_i A_i=P_iY$, где $P_i=X_iX_i^\dagger$. Подстановка даёт максимизацию $\operatorname{tr}(Y^\top(\sum_i P_i)Y)$. Следовательно, берут ведущий собственный репер суммы проекторов, а затем восстанавливают $A_i=X_i^\dagger Y$. Такой подход сохраняет ограничение на $Y$, а нормы отдельных $X_iA_i$ становятся точными только в специальных случаях.

Для двух блоков возьмём каноническую пару $y_1,y_2$ с $\rho>0$. Тогда $P_1 y_2=\rho y_1$, $P_2 y_1=\rho y_2$ и $(P_1+P_2)(y_1+y_2)=(1+\rho)(y_1+y_2)$. Поэтому нормированные проекции общей оси возвращают исходные канонические направления. При $\rho=0$ верхнее собственное подпространство может содержать векторы с нулевой проекцией на один блок, и такая нормировка требует отдельного выбора базиса.

С дополнительным ограничением $A_i^\top A_i=I_r$ простое исключение через псевдообратную перестаёт работать. Обновление $A_i$ для заданного $Y$ принимает форму прямоугольного Прокруста $\|X_iA_i-Y\|_F^2$ из §6.2.4. Идея согласования нескольких конфигураций также лежит в основе обобщённого Прокруста из §6.6.1. В MAXBET максимизируют $\operatorname{tr}(A^\top X^\top XA)=\|\sum_i X_i A_i\|_F^2$ при евклидовой ортонормированности каждого $A_i$. Этот критерий включает и внутриблочные вклады $\|X_i A_i\|_F^2$. Если нормировки делают эти вклады постоянными, остаётся сумма перекрёстных следов.

### 8.7.2. CCA на основе общих главных компонент

Печатные страницы 282–285. В модели общих канонических переменных (CCV) у каждого блока одинаковая ширина $p$, а координаты должны быть содержательно сопоставимы. Ищут единую обратимую $A\in\mathbb R^{p\times p}$ с единичными столбцами, такую что $\Lambda_{ij}=A^\top C_{ij}A$ диагональны для всех пар блоков. В порядке по блокам $\Lambda=[\Lambda_{ij}]$ содержит диагональные матрицы как блоки. После перестановки по каноническим координатам она действительно блочно-диагональна, с $p$ блоками размера $m\times m$.

При обратимых $C_{ii},C_{jj}$ из модели следует

$$
C_{ii}^{-1}C_{ij}C_{jj}^{-1}C_{ji}
=A\,\Lambda_{ii}^{-1}\Lambda_{ij}\Lambda_{jj}^{-1}\Lambda_{ji}A^{-1}.
$$

Поэтому столбцы $A$ задают общие направления, а значение корреляции каждой пары меняется. Квадрат значения на координате $k$ равен $\lambda_{ij,k}^2/(\lambda_{ii,k}\lambda_{jj,k})$. Для произвольных блоков точная модель может быть недостижима. Например, если $C_{ij}$ несимметрична, обратимая конгруэнция $A^\top C_{ij}A$ не может сделать её диагональной и тем самым симметричной.

Для нормальной модели с $Q=I_m\otimes A$, $S=X^\top X/n$ и прогнозируемой ковариацией $Q^{-\top}\Lambda Q^{-1}$ минимизируют отрицательное логарифмическое правдоподобие

$$
\log\det\Lambda-2\log|\det Q|+\operatorname{tr}(\Lambda^{-1}Q^\top S Q).
$$

Поэтому знак направления оптимизации печатной (8.26) нужно сверять с интерпретацией выражения. Масштаб $S$ следует согласовать с масштабом $\Lambda$. При фиксированном $A$ каждая допустимая группа $\Lambda$ обновляется своим главным блоком $Q^\top S Q$ после перестановки. При фиксированной $\Lambda$ переменная $A$ лежит в полноранговой части косоугольного многообразия. Логарифм определителя и решение систем требуют контроля ранга и положительной определённости. Для полного центрированного $S$ условие $n\ge mp$ из текста следует усилить до $n-1\ge mp$ и проверить независимость столбцов.

Далее книга рассматривает JIVE, метод разложения на совместную и индивидуальную вариацию. Здесь данные записаны иначе: $X_i\in\mathbb R^{p_i\times n}$, а блоки сложены по вертикали. После центрирования строк и нормировки блоков по Фробениусу общая часть имеет вид $PDQ^\top$, отдельная часть блока — $U_iD_iV_i^\top$. Ортогональность $V_i^\top Q=0$ разделяет их в пространстве наблюдений. Индивидуальные подпространства разных блоков могут различаться. Для общей и отдельных частей можно выбирать разные ранги.

**Алгоритм 8.1.** Сначала берут усечённую SVD всей матрицы. При фиксированной общей части разбивают остаток по блокам, проецируют каждый $R_i$ справа на $I-QQ^\top$ и находят его усечённую SVD заданного индивидуального ранга. Здесь $Q$ — правый репер общей части в нотации (8.27), независимо от перестановки букв в алгоритме книги. Индивидуальные приближения $U_iD_iV_i^\top$ складывают вертикально. Затем пересчитывают общую часть по SVD $X-X_I$. Чтобы это обновление оставалось точным допустимым шагом при фиксированных $V_i$, можно перед SVD ограничить общую часть общим ортогональным дополнением этих реперов. В простом варианте книги проверяют $\|V_i^\top Q\|_F$ после полного цикла. При ненулевом остатке от заданных рангов практическая остановка следует из стабилизации потери и подпространств, даже если абсолютный остаток выше заданного порога.

## 8.8. Итоги

Печатная страница 285. При полной метрике CCA — это SVD после отбеливания двух блоков. При вырожденной метрике её можно понимать через главные углы между пространствами баллов. Псевдообратная фиксирует представителя коэффициентов, а регуляризация меняет сами ограничения. Разреженные и многоблочные методы дополнительно определяют, какие координаты и какую совместную вариацию следует сохранить.

**Установленный перенос в машинное обучение.** При наличии парных объектов линейный CCA извлекает признаки с максимальной выборочной корреляцией между двумя представлениями. Для оценки переноса нужно вычислять баллы на новых парах с весами и средними, найденными на обучающих данных. Если два высокоразмерных блока натягивают всё центрированное выборочное пространство, положительный результат на обучающих данных возможен даже для случайных пар.

## 8.9. Упражнения

Печатные страницы 286–288. Ниже разобраны задания 1–8. Схемы Manopt даны через целевые функции и евклидовы градиенты. Исполнение MATLAB или Octave и численные примеры из статьи о CCV в рамках разбора не проверялись.

1. **Метки как второй блок.** Ортогональный проектор на $\operatorname{col}(JG)$ равен $JG(G^\top JG)^\dagger G^\top J$. Так как $H$ проектирует на $\operatorname{col}G$, а $\mathbf1\in\operatorname{col}G$, тот же проектор равен $H-\mathbf1\mathbf1^\top/n$. Умножение на $X^\top$ слева и на $X$ справа даёт $B$ из §7.1. При спектральном вычислении псевдообратного квадратного корня положительные собственные значения возводят в степень $-1/2$.
2. **Два единичных балла.** $\|X_1a_1-X_2a_2\|^2=2-2a_1^\top C_{12}a_2$. При полноранговом отбеливании ограничения становятся двумя сферами.
3. **Два репера баллов.** Для общей ширины $r$, $Y_i^\top Y_i=I_r$ даёт $\|Y_1-Y_2\|_F^2=2r-2\operatorname{tr}(A_1^\top C_{12}A_2)$. При разном числе столбцов разность реперов из (8.30) без отдельного сопоставления не определена. Для $m$ блоков суммирование попарных квадратов приводит к матричному SUMCOR.
4. **Общий центр и попарные расстояния.** Пусть $\bar Y=m^{-1}\sum_iY_i$. Раскрытие квадратов даёт $\sum_{i<j}\|Y_i-Y_j\|_F^2=m\sum_i\|Y_i-\bar Y\|_F^2$. В (8.32) тождество верно для квадратов норм. Нормировки $Y_i^\top Y_i=I$ и $Y^\top Y=I$ из разных вариантов задачи связаны, но не гарантируют друг друга. Для двух блоков точная связь через $P_1+P_2$ выведена в §8.7.1.
5. **Общая факторизация блоков.** Для (a) исключить $A_i=X_i^\dagger Y$ и решить задачу для $\sum_iP_i$, как в §8.7.1. Для (b) можно поочерёдно пересчитывать регрессии и ортонормировать $\sum_i X_iA_i$ полярным разложением. Это итерация подпространств для суммы проекторов. Для (c) взять $X_i=G_i$ или $JG_i$ вместе с условием $\mathbf1^\top Y=0$, чтобы первая ось не воспроизводила константу. Свободные оценки категорий дают анализ однородности. В варианте упражнения с дополнительными $\mathrm{St}(p_i,r)$ используем произведение многообразий. Для $(Y,A_1,\ldots,A_m)$ и $E_i=Y-G_i A_i$ градиенты половины суммы квадратов равны $\sum_i E_i$ и $-G_i^\top E_i$. Полезная проверка реализации — центральная разность вдоль ретракции при фиксированном наборе данных.
6. **Блочная форма (8.33).** Обозначим $D=\operatorname{diag}(C_{11},\ldots,C_{mm})$, $S=X^\top X$, $A=[A_1;\ldots;A_m]$. Попарная сумма квадратов — $m\sum_i\|X_iA_i\|_F^2-\|\sum_iX_iA_i\|_F^2=\operatorname{tr}(A^\top(mD-S)A)$. Следовательно, евклидов градиент равен $2(mD-S)A$. При $C_{ii}\succ0$ дальше можно отбелить каждый блок и использовать произведение многообразий Штифеля. Явную составную матрицу можно заменить умножениями на $X_i$ и $X_i^\top$.
7. **Manopt для CCV.** Для фиксированной $\Lambda$ евклидов градиент по $Q$ равен $-2Q^{-\top}+2S Q\Lambda^{-1}$. Градиент по общему $A$ получается суммированием диагональных блоков этой матрицы, поскольку $dQ=I_m\otimes dA$. Его проекция равна $G_A-A\operatorname{Diag}(A^\top G_A)$. Шаг выбирают с контролем обратимости. Затем обновляют $\Lambda$ в координатах §8.7.2 и проверяют градиент вдоль допустимой вариации. **Исследовательское задание.** Для воспроизведения примеров Neuenschwander–Flury нужны те же данные и соглашения о нормировке. Сравнивать решения следует после согласования перестановок и знаков направлений.
8. **Общий индивидуальный репер вместо отдельных.** Если заставить все индивидуальные блоки использовать один $V$, спектральный шаг можно выполнить по сложенному остатку после проекции на $I-QQ^\top$. При тех же индивидуальных рангах единый репер ограничивает множество допустимых решений. Например, при ранге один и двух ненулевых остатках с ортогональными направлениями в пространстве наблюдений отдельные $V_i$ дают точный индивидуальный вклад, а общий $V$ его не воспроизводит. **Исследовательское задание.** Измерить выигрыш по времени и памяти и потерю качества при разных углах между индивидуальными подпространствами.

Для упражнения 5(c) можно задать $Y=KZ$, где столбцы $K$ образуют ортонормированный базис $\mathbf1^\perp$. Тогда $\|Y-G_iA_i\|_F^2$ отличается от $\|Z-K^\top G_iA_i\|_F^2$ слагаемым $\|(\mathbf1\mathbf1^\top/n)G_iA_i\|_F^2$. Фрагмент ниже решает вариант с **центрированными** индикаторами, то есть вторую задачу. Вход $G$ — непустой массив индикаторных матриц с одинаковым числом строк. Необходимо $1\le r\le\min(n-1,p_1,\ldots,p_m)$. [Произведения многообразий в Manopt](https://www.manopt.org/manifolds.html)

~~~matlab
function [Y, A] = categorical_gcca(G, r)
    m = numel(G);
    n = size(G{1}, 1);
    K = null(ones(1, n));
    names = cell(1, m);
    X = cell(1, m);
    factors.Z = stiefelfactory(n-1, r);
    for i = 1:m
        names{i} = sprintf('A%d', i);
        X{i} = K' * G{i};
        factors.(names{i}) = stiefelfactory(size(G{i}, 2), r);
    end
    problem.M = productmanifold(factors);
    problem.cost = @cost;
    problem.egrad = @egrad;
    checkgradient(problem);
    point = conjugategradient(problem);
    Y = K * point.Z;
    A = cell(1, m);
    for i = 1:m
        A{i} = point.(names{i});
    end

    function f = cost(point)
        f = 0;
        for i = 1:m
            residual = point.Z - X{i} * point.(names{i});
            f = f + 0.5 * norm(residual, 'fro')^2;
        end
    end

    function Gout = egrad(point)
        Gout.Z = zeros(size(point.Z));
        for i = 1:m
            residual = point.Z - X{i} * point.(names{i});
            Gout.Z = Gout.Z + residual;
            Gout.(names{i}) = -X{i}' * residual;
        end
    end
end
~~~

Этот вариант хранит плотный $K$ и подходит для небольших примеров. Для большого числа наблюдений нужно применять центрирование и переход к $\mathbf1^\perp$ без хранения такого базиса. Проверки результата — $\mathbf1^\top Y=0$, $Y^\top Y=I_r$ и $A_i^\top A_i=I_r$ с численным допуском.
