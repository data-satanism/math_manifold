# 09. Общие главные компоненты

[Карта разбора монографии](30_mathematics/matrix-manifolds-manopt/mda-map) · Печатные с. 289–324.

## Простыми словами

Если одна и та же совокупность признаков измерена в нескольких группах, обычный PCA выдаёт каждой группе собственные оси. Общие главные компоненты (CPC) ищут **одну систему осей для всех групп**. Разброс вдоль осей может различаться. Например, ковариации $\operatorname{diag}(9,1)$ и $\operatorname{diag}(4,6)$ имеют общие оси, хотя первая по дисперсии компонента у них разная. Если повернуть только второй эллипс, оси перестают совпадать и способ подгонки определяет компромисс.

Понадобятся спектральное разложение вещественной симметричной матрицы, след, норма Фробениуса и касательное пространство к ортогональной группе. Авторы поочерёдно меняют меру ошибки, число общих осей и допустимое отношение между групповыми спектрами. [Матричные многообразия](30_mathematics/matrix-manifolds-manopt/chapters/mda-03-matrix-manifolds) · [Анализ главных компонент](30_mathematics/matrix-manifolds-manopt/chapters/mda-04-pca).

## 9.1. Введение

Печатная с. 290. CPC ослабляет предположение об одинаковых ковариациях, на котором основана классическая модель линейного дискриминантного анализа (LDA). Если группы имеют общие оси, можно использовать единый поворот признаков и оценивать вдоль этих осей отдельные групповые дисперсии. Модель пропорциональных главных компонент (PPC) накладывает дополнительное ограничение: масштабы дисперсий меняются между группами одним множителем на группу.

На рис. 9.1 показаны решения на данных об ирисах Фишера с тремя и двумя ошибками классификации. Авторы отмечают, что второй результат встречался при редких запусках. Этот рисунок иллюстрирует зависимость численного результата от запуска. Для оценки качества на новых данных нужны разбиение выборки, подбор осей только на обучающей части и сравнение с LDA по общей метрике.

## 9.2. Постановки оценивания CPC

Печатная с. 293. Пусть $S_i\in\mathbb R^{p\times p}$ — симметричная выборочная ковариация группы $i$, $n_i>0$ — её вес, $i=1,\ldots,k$. В книге веса нормальной модели связаны с числом степеней свободы. Популяционная гипотеза имеет вид $\Sigma_i=Q\Lambda_i Q^\top$, где $Q\in O(p)$ и $\Lambda_i=D_i^2$ — положительная диагональная матрица. Обозначим $X_i=Q^\top S_i Q$, $\operatorname{Diag}(X_i)$ — матрицу с сохранённой диагональю и $\operatorname{off}(X_i)=X_i-\operatorname{Diag}(X_i)$.

При нормальной модели минимизация отрицательного логарифма правдоподобия с точностью до постоянного множителя и слагаемого даёт

$$
F_{\mathrm{ML}}=\sum_i n_i\bigl(\log\det\Lambda_i+
                         \operatorname{tr}(\Lambda_i^{-1}X_i)\bigr).
$$

Аналог по методу наименьших квадратов имеет вид

$$
F_{\mathrm{LS}}=\sum_i n_i\|S_i-Q\Lambda_i Q^\top\|_F^2.
$$

Для $S_i\succeq0$ модель LS допускает нулевые диагональные значения $\Lambda_i$. В ML обратная матрица и логарифм требуют $\Lambda_i\succ0$. При $q_j^\top S_iq_j=0$ вклад $\log\lambda_{ij}$ уходит к $-\infty$ при $\lambda_{ij}\downarrow0$. Для сингулярных данных можно рассматривать LS или отдельно обосновывать регуляризацию ML. Параметризация $\Lambda_i=D_i^2$ сама по себе допускает ноль.

**Когда общие оси существуют точно.** Вещественные симметричные матрицы имеют общий ортонормированный собственный базис тогда и только тогда, когда $S_iS_j=S_jS_i$ для всех пар. Необходимость следует из коммутирования диагональных матриц. Для достаточности разложим пространство на собственные подпространства $S_1$. Из коммутирования следует, что каждое из них инвариантно относительно остальных $S_i$. Повторяем спектральное разложение внутри подпространств для $S_2,\ldots,S_k$. Если два направления имеют одинаковые наборы собственных значений по всем группам, поворот внутри их общего собственного подпространства остаётся свободным. Знаки и общая перестановка столбцов свободны всегда.

## 9.3. Оценивание по максимальному правдоподобию и наименьшим квадратам

Печатная с. 294. Авторы сравнивают стационарность двух целей в одних и тех же переменных и затем вычисляют решения для трёх групп ирисов.

### 9.3.1. Градиенты и условия оптимальности

Печатная с. 294. При фиксированном $Q$ вклад одной диагональной координаты в ML равен $\log\lambda+x/\lambda$, где $x=q_j^\top S_iq_j>0$. Производная равна $(\lambda-x)/\lambda^2$, поэтому минимум достигается при $\lambda=x$. В LS ортогональная инвариантность нормы даёт $\|S_i-Q\Lambda_iQ^\top\|_F^2=\|X_i-\Lambda_i\|_F^2$, а минимум по диагонали также достигается при $\Lambda_i=\operatorname{Diag}(X_i)$. Для параметра $d$ с $\lambda=d^2$ у LS есть дополнительная стационарная точка $d=0$ даже при $x>0$. Вдоль этой координаты $d=0$ тогда не является минимумом.

По $Q$ допустимые направления имеют вид $Q\Omega$, $\Omega^\top=-\Omega$. Для последующей проверки кода можно продифференцировать продолжения критериев при фиксированных $\Lambda_i$ и использовать евклидовы градиенты

$$
G_{\mathrm{ML}}=2\sum_i n_i S_iQ\Lambda_i^{-1},\qquad
G_{\mathrm{LS}}=-4\sum_i n_i S_iQ\Lambda_i.
$$

Для LS отброшены слагаемые, постоянные на $O(p)$. Производная равна $\langle Q^\top G,\Omega\rangle_F$. Она обнуляется по всем кососимметричным $\Omega$ тогда и только тогда, когда $Q^\top G$ симметрична. Так получаются условия теорем 9.3.1–9.3.2 на с. 295. В матричных суммах нужно сохранить веса $n_i$ из целевых функций, опущенные в печатных условиях. После подстановки диагоналей суммы содержат $\Lambda_i^{-1}$ для ML и $\Lambda_i$ для LS. Это объясняет, почему решения могут расходиться при несовместимых ковариациях. При точной одновременно диагонализируемой положительно определённой семье обе цели достигают минимумов на общем собственном базисе. Стационарность сама по себе не гарантирует минимум. Для одиночной неравномерной диагонали поворот на $45^\circ$ может уравнять диагональные элементы при ненулевом внедиагональном остатке.

**Вычислимый пример.** Возьмём из введения $S_1=\operatorname{diag}(9,1)$ и повернём $S_2=\operatorname{diag}(4,6)$ на $45^\circ$. Получим $S_2=\begin{pmatrix}5&-1\\-1&5\end{pmatrix}$ и $[S_1,S_2]=\begin{pmatrix}0&-8\\8&0\end{pmatrix}$. При равных весах профильный LS для поворота $Q(\theta)$ равен $32\sin^2(2\theta)+2\cos^2(2\theta)$. Минимум равен $2$, и базис при $\theta=0$ сохраняет оси $S_1$. Больший размах его спектра даёт большую цену поворота.

![Один базис поворачивается для двух ковариационных эллипсов с несовпадающими осями.](80_assets/matrix-manifolds-manopt/pca-geometry-v1/mda-09-cpc.png)

Обе ковариации фиксированы. На каждом кадре показан один принятый градиентный шаг по общему углу. Из-за несовпадающих собственных осей остаток остаётся положительным. Две высоты разделяют выборки, а собственные масштабы эллипсов вычислены по одной шкале.

### 9.3.2. Пример с ирисами Фишера

Печатная с. 296. В книге сопоставлены ML-оценки Manopt и алгоритма Флури–Гаучи (FG), затем приведена LS-оценка. Например, первая осевая дисперсия для второй группы около $69{,}15$ у ML Manopt, $69{,}22$ у FG и $69{,}38$ у LS. Для четвёртой оси той же группы ML Manopt даёт около $5{,}36$, а LS около $4{,}41$. Чтобы сравнить направления, сначала согласуют знаки и перестановку столбцов, затем смотрят на $|q_a^\top q_b|$ и остатки по группам. В таблицах этой главы осевые дисперсии относятся к данным и масштабу, использованным авторами.

### 9.3.3. Приложение. Код алгоритма Флури–Гаучи на MATLAB

Печатная с. 297. Листинг задаёт три ковариации размера $4\times4$ и веса `n_g`, равные $(49,49,49)$. Во внешнем цикле он обходит пары столбцов $B$, вычисляет блоки $T_i=b^\top S_i b$ размера $2\times2$ и применяет поворот Гивенса. Функция `G_alg` строит взвешенную матрицу из $T_i$ с коэффициентами $(\delta_1-\delta_2)/(\delta_1\delta_2)$, где $\delta_a$ — текущие осевые дисперсии пары. Функция `symschur2` получает косинус и синус из диагонализации одного симметричного блока. Отображаемая цель складывает логарифмы диагональных дисперсий с весами. Слагаемое со следом в профильной цели постоянно.

В теле `G_alg` на с. 298–299 видно присваивание `Q=Qnew`. После вычисления `c,s` обновления `Qnew` нет. При буквальном чтении внутренний цикл завершается после первого прохода. Внешний цикл продолжает обновлять $B$. Для переноса процедуры следует сверить внутреннюю итерацию с алгоритмом FG и проверять $\|B^\top B-I\|_F$, фактическое изменение профильной цели и остаток стационарности. Околонулевые $\delta_a$ делают коэффициенты неустойчивыми. Листинг сверили по печатным страницам. Выполнение в MATLAB не проверялось.

## 9.4. Новые способы оценивания CPC

Печатная с. 299. Вначале авторы исключают из задачи диагональные параметры, затем рассматривают поток на совместной орбите матриц и обратную задачу при заданных осевых дисперсиях.

### 9.4.1. Классические численные решения для ML и LS

Печатная с. 299. После обновления $\Lambda_i=\operatorname{Diag}(Q^\top S_iQ)$ в ML след равен $p$ для каждой группы. Цель FG поэтому равна $\sum_i n_i\sum_j\log(q_j^\top S_iq_j)$ с точностью до постоянного слагаемого. Аналогичное исключение параметров в LS оставляет $\sum_i n_i\|\operatorname{off}(Q^\top S_iQ)\|_F^2$. Другой алгоритм чередует оптимизацию $Q$ при фиксированных $\Lambda_i$, как в (9.15), и обновление диагоналей. Поэтапное улучшение требует, чтобы обновление $Q$ действительно уменьшало цель. Сравнение отражённых и переставленных решений делают после согласования базисов.

### 9.4.2. Прямое вычисление индивидуальных дисперсий

Печатная с. 300. Для $Q(t)\in O(p)$ пишем $\dot Q=Q\Omega$, $\Omega^\top=-\Omega$. Тогда

$$
\dot X_i=\dot Q^\top S_iQ+Q^\top S_i\dot Q=[X_i,\Omega],\qquad X_i(0)=S_i .
$$

В записи (9.18)–(9.20) общий генератор потока для всех групп имеет вид $\Omega_{\mathrm{ML}}=\sum_l n_l[\operatorname{Diag}(X_l)^{-1},X_l]$ для ML и $\Omega_{\mathrm{LS}}=-\sum_l n_l[\operatorname{Diag}(X_l),X_l]$ для LS. Индекс $l$ суммирует группы, тогда как индекс $i$ выбирает матрицу, которую обновляют. С точностью до положительного масштаба времени это потоки спуска для профильных критериев. Общий кососимметричный генератор сохраняет спектр каждой матрицы и совместность поворота. Из предельного $X_i$ читают диагональ оценённой модели. При ненулевом остатке это осевые дисперсии $q_j^\top S_iq_j$, а собственные значения самой $S_i$ сохраняются на всём пути. При численном интегрировании проверяют сохранение спектров, снижение цели и норму генератора. Стационарный генератор может обращаться в ноль за счёт взаимной компенсации групп.

### 9.4.3. CPC при известных индивидуальных дисперсиях

Печатная с. 302. Если $\Lambda_i$ заданы с общей нумерацией осей, ML сводится к минимизации $\sum_i n_i\operatorname{tr}(\Lambda_i^{-1}Q^\top S_iQ)$, а LS — к максимизации $\sum_i n_i\operatorname{tr}(\Lambda_i Q^\top S_iQ)$. Критерии эквивалентны суммам прокрустовых ошибок $\|S_iQ+Q\Lambda_i^{-1}\|_F^2$ и $\|S_iQ-Q\Lambda_i\|_F^2$ соответственно. При раскрытии квадрата обе нормы отдельных слагаемых постоянны на $O(p)$, и след появляется из перекрёстного члена. Совместный поиск по нескольким группам требует отдельного численного решения. В эксперименте книги диагонали из потоков восстанавливают для Iris почти те же направления, что и исходные критерии.

## 9.5. CPC для понижения размерности

Печатная с. 303. Полный базис заменяют матрицей $Q\in\mathrm{St}(p,r)$, $Q^\top Q=I_r$, где $r<p$. При подгонке $\sum_i n_i\|S_i-Q\Lambda_iQ^\top\|_F^2$ исключение диагоналей оставляет максимизацию $\sum_{i,j}n_i(q_j^\top S_iq_j)^2$. Это частный случай ортонормированного INDSCAL. Захваченная дисперсия измеряется другой величиной $\sum_i\operatorname{tr}(Q^\top S_iQ)$ или её взвешенным вариантом. В примере Iris авторы приводят для ортонормированного INDSCAL сумму $158{,}7684$ против $157{,}9248$ для первых двух осей полного LS-CPC.

У ML выражение $Q\Lambda_iQ^\top$ ранга $r$ нельзя подставить в обычное правдоподобие полного ранга. Можно подгонять ковариации $Q^\top S_iQ$ в проекции. Если требуется удержать дисперсию, минимизация (9.25) с заданными положительными весами благоприятствует малым дисперсиям. Авторы вводят максимизацию (9.26), которая меняет статистическую цель и вознаграждает большие осевые дисперсии. Для Iris в книге приведены суммы $23{,}7329$ и $158{,}5090$ соответственно.

Для заданных весов $\alpha_{ij}>0$ цель имеет вид $\sum_j q_j^\top M_jq_j$, $M_j=\sum_i n_i\alpha_{ij}S_i$. Покомпонентная схема ищет очередной единичный $q_j$ в ортогональном дополнении ранее выбранных столбцов. Пусть $P_{j-1}=I-Q_{j-1}Q_{j-1}^\top$. Условие теоремы 9.5.1 в этой записи равно $(P_{j-1}-q_jq_j^\top)M_jq_j=0$. Оно следует из зануления производной вдоль касательной к сфере в $\operatorname{range}P_{j-1}$. Последовательное решение может уступать совместному: для $M_1=\operatorname{diag}(5,4,0)$ и $M_2=\operatorname{diag}(100,0,0)$ жадный выбор даёт $q_1=e_1$ и сумму $5$, тогда как $q_1=e_2$, $q_2=e_1$ дают $104$.

Алгоритм 9.1 обновляет веса по текущим $\mu_i=q^\top S_iq$. В ветви ML вес равен $n_i/\mu_i$, в ветви LS — $n_i\mu_i$. Умножение на взвешенную сумму $S_i$ сопровождается проекцией и нормировкой, а после выбора оси проектор уменьшается на $q_jq_j^\top$. Для воспроизведения нужно нормировать начальный вектор после проекции, обработать нулевую норму обновления и контролировать малые $\mu_i$. В неявной реализации при $S_i=Z_i^\top Z_i$ умножение можно вычислять через $Z_i^\top(Z_iq)$ без формирования плотной ковариации.

## 9.6. Пропорциональные ковариации

Печатная с. 309. PPC предполагает $\Sigma_i=c_i A$, $c_i>0$ и $c_1=1$. Все группы делят не только оси, но и отношения дисперсий между осями. Фиксация $c_1$ устраняет неоднозначность общего масштаба. Например, $\operatorname{diag}(9,1)$ и $\operatorname{diag}(18,2)$ удовлетворяют PPC, а пара из начала главы удовлетворяет только CPC.

### 9.6.1. Пропорциональные компоненты по ML и LS

Печатная с. 309. Для заданных $c_i$ в ML стационарная оценка $A$ равна $\sum_i n_i S_i/c_i\big/\sum_i n_i$, если эта матрица положительно определена. Для фиксированной $A$ свободный $c_i$ равен $\operatorname{tr}(A^{-1}S_i)/p$. Формула следует из дифференцирования $p\log c_i+\operatorname{tr}(A^{-1}S_i)/c_i$. В LS для фиксированной ненулевой $A$ ненормированный коэффициент равен $\langle S_i,A\rangle_F/\|A\|_F^2$, а для заданных коэффициентов оптимальная полная $A$ равна

$$
\bar S_c=\frac{\sum_i n_i c_iS_i}{\sum_i n_i c_i^2}.
$$

При $S_i\succeq0$ и положительных коэффициентах $\bar S_c\succeq0$. Обновление коэффициента может дать ноль при ортогональных носителях. При строгом условии $c_i>0$ это предупреждает о граничном поведении. Спектральное разложение $\bar S_c$ даёт общие оси. На данных Iris книга сообщает LS-ошибки $129{,}1579$ у PPC и $93{,}3166$ у CPC при принятом авторами масштабе. Подмножество допустимых ковариаций у PPC уже, поэтому глобальная LS-ошибка при прочих равных не может стать меньше.

### 9.6.2. Понижение размерности с PPC

Печатная с. 313. При фиксированных $c_i$ раскрытие квадратов сводит LS к приближению $\bar S_c$ матрицей $A$ ранга не выше $r$. Для $\bar S_c\succeq0$ оставляют $r$ ведущих собственных пар и повторно оценивают $c_i$. Фактор $r$ влияет и на подпространство, и на пропорции. В книге для двух LS-PPC сообщены коэффициенты $1$, $1{,}4349$, $0{,}3233$ и значение цели $161{,}727$. В ML при прямоугольном $Q$ определитель и обратная матрица должны относиться к модели размерности $r$ в проекции либо к полноранговой модели с явно описанным остатком. У ковариации $QDQ^\top$ ранга $r<p$ определитель равен нулю, и (9.34) к ней напрямую неприменима.

## 9.7. Связь CPC и анализа независимых компонент

Печатная с. 315. Анализ независимых компонент (ICA) использует тот же вычислительный приём совместной диагонализации, когда статистики источников подготавливают набор подходящих матриц. Выбор этих матриц связан с типом информации об источниках, например временной структурой или кумулянтами.

### 9.7.1. Постановки ICA

Печатная с. 315. Модель наблюдения имеет вид $x=As+\varepsilon$, где $A$ смешивает латентные источники, а компоненты $s$ независимы. В версии без шума $\varepsilon=0$. Независимость влечёт нулевую ковариацию при существующих вторых моментах. Обратная импликация верна для совместно гауссовских переменных. Для симметричной $z$ с конечным четвёртым моментом $z$ и $z^2$ некоррелированы. Если $z^2$ меняется, эти величины зависимы, поскольку второе значение вычисляется из первого. Диагональная ковариация после PCA поэтому не удостоверяет успешную ICA.

### 9.7.2. ICA через контрастные функции

Печатная с. 316. Квадратная модель без шума после центрирования, отбеливания и нормировки дисперсий источников даёт ортогональную $A$. Тогда $s=A^\top x$, якобиан по модулю равен единице, и при известных плотностях контраст имеет вид $\sum_{t,j}\log f_j(a_j^\top x_t)$. При матрице наблюдений $X$ по строкам евклидов градиент равен $X^\top G$, где $G_{tj}=(\log f_j)'((XA)_{tj})$. Условие стационарности требует симметрии $A^\top X^\top G$. Идентифицируемость обычной квадратной модели требует не более одного гауссовского источника и оставляет неоднозначности знаков, масштаба до нормировки и перестановки.

Альтернатива — приближённая негэнтропия $[\mathbb E g(a^\top x)-\mathbb E g(z)]^2$ для стандартного гауссовского $z$. Книжный критерий $\mathbb E g(a^\top x)$ соответствует выбору ветви отклонения. Для исходного квадрата нужно учитывать обе стороны от гауссовского значения. Градиент нелинейного среднего на сфере получается из евклидова умножением на $I-aa^\top$. При последовательном поиске из него дополнительно исключают найденные направления. Можно также найти все столбцы за одну оптимизацию на $O(p)$, подставив соответствующий контраст и его производную.

### 9.7.3. ICA через совместную диагонализацию

Печатная с. 320. SOBI строит матрицы лаговых ковариаций после отбеливания и использует различия временных профилей источников. Для симметричных матриц минимизация суммы квадратов внедиагональных элементов совпадает с профильным LS-CPC при тех же весах. Если матрицы лаговых ковариаций в выборке несимметричны, следует задать способ симметризации или явно работать с выбранным асимметричным критерием. JADE применяет совместную диагонализацию к матрицам кумулянтов четвёртого порядка. Совпадающие лаговые профили и отсутствие различимых кумулянтов могут оставить целое подпространство неидентифицируемым. Использование разных статистик даёт разную чувствительность к шуму и выбросам.

Варианты на $GL(p)$ используют общий невырожденный преобразователь. Замена $Q$ на $\varepsilon Q$ умножает исходную цель $\sum_i\|\operatorname{off}(QC_iQ^\top)\|_F^2$ на $\varepsilon^4$, так что её можно уменьшить простым сжатием масштаба. Критерий (9.68) реконструирует исходные матрицы через $Q^{-1}\operatorname{Diag}(QC_iQ^\top)Q^{-\top}$ и инвариантен к перенормировке строк. Ограничение $\det Q=1$ запрещает общий скалярный коллапс. Последовательность допустимых матриц всё ещё может иметь растущую норму и плохую обусловленность, например $\operatorname{diag}(t,t^{-1})$ при $t\to\infty$. Любой конечный предел матриц из $SL(p)$ принадлежит группе по непрерывности определителя. Сомнение в этом на с. 322 вызвано смешением замкнутости с компактностью. В варианте с единичными столбцами для модели $Q\Lambda_iQ^\top$ ранг $Q$ проверяют отдельно, поскольку произведение сфер разрешает совпадающие столбцы.

## 9.8. Выводы

Печатная с. 323. Для нескольких ковариаций можно оценить общий базис, ограничиться несколькими направлениями или потребовать пропорциональности всех спектров. Выбор определяет, какие параметры разделяют группы, что можно считать статистическим правдоподобием и где появляются обращения матриц. В вычислительном отчёте удобно сопоставлять ошибку по каждой группе, захваченную дисперсию, невязку ортогональности и разброс результатов между начальными приближениями.

**Установленная связь с машинным обучением.** SOBI и JADE используют структуру статистик источников для слепого разделения сигналов. Одновременная диагонализация сама по себе устанавливает только совместимость выбранных статистик с найденным базисом.

**Исследовательский вопрос.** Можно ли подобрать общий базис для ковариаций эмбеддингов в нескольких доменах так, чтобы он сохранял прогнозные направления на новом домене? Это проверяется на отложенных доменах сравнением CPC, PCA объединённых данных и отдельных PCA при одинаковом ранге. Хорошая диагонализация в обучающих доменах не исключает сдвига условного распределения меток.

## 9.9. Упражнения

Печатная с. 324. Ниже приведены опорные шаги для всех семи задач.

1. **Эквивалентность (9.66) и (9.6).** В LS поворотом перенесите $S_i$ в базис $Q$. Минимизация по диагонали оставляет $\operatorname{off}(Q^\top S_iQ)$. Согласуйте ориентацию $Q$ и $Q^\top$ и сравните задачи при равных весах или внесите одинаковые веса в обе суммы.
2. **Диагональное масштабирование в (9.68).** Для диагональной невырожденной $D$ имеем $\operatorname{Diag}(DAD)=D\operatorname{Diag}(A)D$. Подстановка $DQ$ в восстановление даёт множители $D^{-1}$ с двух сторон, которые сокращаются.
3. **(9.68) на $O(p)$.** Умножьте остаток слева на $Q$ и справа на $Q^\top$. Норма сохраняется и остаётся внедиагональный остаток преобразованной матрицы.
4. **Критерий обратимости.** Если $(I+A)v=0$ для $v\ne0$, то $\|A\|_F\ge\|A\|_2\ge\|Av\|/\|v\|=1$.
5. **Некомпактность $SL(2)$.** Матрицы $\begin{pmatrix}1&t\\0&1\end{pmatrix}$ имеют определитель один и неограниченную норму при $|t|\to\infty$.
6. **Нижняя граница нормы.** Для сингулярных чисел $\prod_j\sigma_j=1$. Неравенство между средним арифметическим и геометрическим даёт даже $\|Q\|_F\ge\sqrt p$.
7. **Связность $SL(p)$.** Из полярного разложения $Q=UP$ имеем $U\in SO(p)$ и $P\succ0$, $\det P=1$. Путь $P^t$ сохраняет определитель. Любой $U\in SO(p)$ соединяется с единицей непрерывным включением плоских поворотов. Для $p=1$ группа состоит из одной точки.
