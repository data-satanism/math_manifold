# 07. Линейный дискриминантный анализ

[К карте курса](30_mathematics/matrix-manifolds-manopt/mda-map)

Линейный дискриминантный анализ (LDA) строит признаки, по которым центры известных классов хорошо различаются относительно разброса внутри классов. Для полной матрицы внутриклассового разброса это спектральная задача. Когда признаков больше, чем наблюдений, нулевой знаменатель может означать как идеальное разделение на выборке, так и отсутствие информации. От этого различия зависит выбор метода.

Для вывода достаточно знать ортогональную проекцию, [сингулярное разложение](30_mathematics/tyrtyshnikov-video-2026/lectures/tva-04-svd-least-squares) и [разницу между квадратным преобразованием и прямоугольным репером](30_mathematics/matrix-manifolds-manopt/chapters/mda-06-procrustes).

## Простыми словами

Представим две вытянутые группы точек. Ось, на которой центры далеко друг от друга, может давать сильное перекрытие, если обе группы вытянуты вдоль неё. LDA делит квадрат расстояния между центрами на внутриклассовый разброс по этой же оси. Так из длинного списка признаков получают один или несколько дискриминантных баллов.

Если внутри каждой группы наблюдения дают один и тот же балл, а у групп баллы разные, разделение на выборке точное. Если балл одинаков вообще для всех наблюдений, такое направление можно отбросить. В вырожденном случае обычная формула $W^{-1}B$ теряет обе ситуации сразу. Метод нулевого пространства и нормировка по полному разбросу позволяют различить их.

## 7.1. Введение

Печатные страницы 230–233. Пусть $X\in\mathbb R^{n\times p}$, а $G\in\{0,1\}^{n\times g}$ содержит по одной единице в строке и задаёт принадлежность к $g$ непустым классам. Тогда $N=G^\top G=\operatorname{diag}(n_1,\ldots,n_g)$, $\overline X=N^{-1}G^\top X$ содержит центры классов, а $H=GN^{-1}G^\top$ — проектор на векторы, постоянные внутри класса. Пусть $P_1=\mathbf1\mathbf1^\top/n$, $J=I-P_1$ и $P_B=H-P_1$. Обозначим $X_T=JX$, $X_W=(I-H)X$, $X_B=P_BX$. Во всех трёх случаях матрицы имеют $n$ строк. Для межклассового разброса можно также хранить только $g$ строк с отклонениями центров, взвешенными на $\sqrt{n_i}$.

$$
T=X^\top JX=X_T^\top X_T,\qquad
W=X^\top(I-H)X=X_W^\top X_W,\qquad
B=X^\top P_BX=X_B^\top X_B .
$$

В книге $B,W,T$ — суммы квадратов и попарных произведений. Проекторы $P_B$ и $I-H$ взаимно ортогональны и в сумме дают $J$. Значит, $T=B+W$, $\operatorname{rank}B\le g-1$, $\operatorname{rank}W\le n-g$ и $\operatorname{rank}T\le n-1$. Геометрическая постановка Фишера использует эти расчёты без распределительной модели. Интерпретация линейных баллов как байесовского правила следует при нормальных распределениях классов с общей невырожденной ковариацией.

## 7.2. LDA при избытке наблюдений

Печатные страницы 233–235. Для одного балла $Xa$ критерий Фишера $\lambda(a)=a^\top Ba/(a^\top Wa)$ максимизируется там, где знаменатель положителен. При $W\succ0$ замена на $\mu(a)=a^\top Ba/(a^\top Ta)$ сохраняет порядок направлений, потому что $\mu=\lambda/(1+\lambda)$. Из $0\preceq B\preceq T$ следует $0\le\mu\le1$. Для двух положительно полуопределённых матриц $\ker T=\ker W\cap\ker B$: если $a^\top Ta=0$, то суммы квадратов $a^\top Wa$ и $a^\top Ba$ по отдельности нулевые. Это уточняет печатное (7.10).

Объёма $n>p$ самого по себе мало для обратимости $W$. Нужны $p$ линейно независимых столбцов внутриклассовых остатков, следовательно, необходимо $p\le n-g$. При общей нормальной ковариации и заранее фиксированном $a$ статистика $(a^\top Ba/(g-1))/(a^\top Wa/(n-g))$ имеет под нулевой гипотезой распределение $F_{g-1,n-g}$. Направление, выбранное по максимуму на той же выборке, требует другого теста.

### 7.2.1. Стандартные канонические переменные

Печатные страницы 235–240. Из максимума $a^\top Ba$ при $a^\top Wa=1$ получаем $Ba=\lambda Wa$. Пусть $W=R^\top R$ — разложение Холецкого при $W\succ0$. Для $u=Ra$ решаем симметричную задачу

$$
R^{-\top}BR^{-1}u=\lambda u,\qquad a=R^{-1}u.
$$

Ортонормированные собственные векторы $u$ дают репер $A^\top WA=I$ в исходных координатах. Число ненулевых дискриминантных направлений не превышает $g-1$. При кратных собственных значениях можно однозначно выделить соответствующее собственное подпространство, а выбор базиса в нём остаётся свободным. Если разложение плохо обусловлено, отслеживают численный ранг и используют разложение с контролем спектра. Треугольные системы решают без явного построения обратных матриц.

Эквивалентная запись через обобщённое сингулярное разложение (GSVD) работает с факторами $(X_B,X_T)$. В координатах, где обе квадратичные формы диагональны, $\mu_i=\|X_B a_i\|^2/\|X_T a_i\|^2$ для ненулевого знаменателя. Формула (7.19) на с. 237 меняет местами обозначения $\alpha,\beta$ по сравнению с предшествующей строкой. Инвариантный способ проверить порядок — $B\preceq T$ и $0\le\mu_i\le1$.

В таблицах 7.1–7.2 для 32 черепов книга сравнивает три способа читать нагрузки. Исходный коэффициент $a_j$ зависит от единицы измерения. Стандартизованный коэффициент умножает его на масштаб внутриклассового разброса признака. Коэффициент структуры — корреляция $X_j$ с баллом $Xa$. Для $x_2$ модуль исходного коэффициента велик, а корреляция с баллом около $-0{,}048$. Условный вклад признака в линейную комбинацию и его индивидуальная корреляция описывают разные свойства. При коррелирующих признаках сами коэффициенты могут быть чувствительны к выборке.

**Ручная проверка.** При $B=dd^\top$, $d=(1,1)^\top$, $W=\operatorname{diag}(1,4)$ получаем $a\propto(1,1/4)^\top$ и максимум $d^\top W^{-1}d=5/4$. Это также следует из неравенства Коши — Буняковского для $W^{1/2}a$ и $W^{-1/2}d$. Евклидова ось $d/\sqrt2$ даёт отношение $4/5$.

### 7.2.2. Евклидово ортогональные канонические переменные

Печатные страницы 240–241. В ортогональной версии (OCV) на каждом шаге максимизируют то же отношение $a^\top Ba/a^\top Wa$, но задают $a^\top a=1$ и $A_{\rm prev}^\top a=0$. Алгоритм строит ортонормированный базис $Z$ дополнения к уже найденным направлениям и решает локальную обобщённую спектральную задачу для $Z^\top BZ,Z^\top WZ$. На первом шаге выбор нормировки меняет только масштаб. Начиная со второго шага, меняется допустимое подпространство. Для предыдущего примера $W$-ортогональное дополнение к первому направлению натянуто на $(1,-1)^\top$, евклидово ортогональное — на $(1,-4)^\top$.

В таблице 7.3 заново нормированные исходные нагрузки для данных по черепам отличаются от таблицы 7.2. При одном направлении максимум тот же. Выигрыш от евклидовой ортогональности состоит в том, что $AA^\top$ — ортогональный проектор исходного пространства признаков. Ортогональность весов $a_i$ сама по себе не гарантирует отсутствия корреляции между баллами $Xa_i$.

## 7.3. Разреженные канонические переменные

Печатные страницы 241–248. В DALASS добавляют ограничение $\|a\|_1\le\tau$ на вектор единичной евклидовой нормы. Тогда $1\le\|a\|_1\le\sqrt p$. На практике книга использует внешний штраф $\gamma\max(0,\|a\|_1-\tau)$ в последовательной максимизации. Для градиентного метода на сфере нужны субградиент либо согласованное сглаживание штрафа. При сглаживании маленькие значения следует отличать от точных нулей и проверять условие после порогового отсечения.

В формуле (7.26) сферический вектор относится к отбеленным координатам. Ограничить его $\ell_1$-норму проще, но исходные веса равны $R^{-1}u$ и при плотном $R^{-1}$ могут снова стать плотными. Например, $R=\bigl(\begin{smallmatrix}1&1\\0&1\end{smallmatrix}\bigr)$ переводит $u=e_2$ обратно в $(-1,1)^\top$. Для разреженности в исходных признаках штраф нужно вычислять по $R^{-1}u$ либо оптимизировать отношение в исходных координатах, как в (7.27). При последовательных шагах выбранная метрика определяет и ортогональное дополнение.

В примере с черепами при $\tau=1{,}2$ у стандартного DALASS преобладает $x_1$, у ортогонального — $x_4$. Значения критерия по отчёту авторов составляют $19{,}933$ и $22{,}050$ против $28{,}012$ у плотного решения. На Iris, где три класса и четыре признака, рисунки 7.1–7.2 показывают две оси и разную геометрию проекций. В разреженной ортогональной версии доминируют ширина лепестка на первой оси и длина лепестка на второй. В плотных версиях авторы приводят три и четыре ошибки на исходных 150 объектах. В разреженных версиях — четыре и пять. Это оценка на тех же данных. Вид проекций и величины отдельных отношений сами по себе не определяют ошибку на новых объектах.

## 7.4. LDA при избытке признаков

Печатные страницы 248–249. При $p>n$ матрица $W$ вырождена по рангу. Авторы группируют решения по четырём идеям: усилить диагональ $W$, переопределить задачу без явного обращения, исследовать нулевое пространство либо ввести отдельную статистическую модель ковариации. Предварительный PCA может помочь с размерностью, но способен удалить важное направление. При $W=\operatorname{diag}(100,0)$, $B=\operatorname{diag}(0,1)$ ведущая компонента полного разброса $T$ — $e_1$, хотя всю межклассовую информацию несёт $e_2$.

### 7.4.1. LDA через обобщённое сингулярное разложение

Печатные страницы 249–250. Пусть $X_T=U\Sigma V^\top$ — тонкое SVD только с $s$ положительными сингулярными числами. Тогда $a=V\Sigma^{-1}z$ даёт $X_Ta=Uz$, $X_Ba=P_B Uz$ и $a^\top Ta=\|z\|^2$. Следовательно, $\mu$ — квадраты сингулярных чисел $P_B U$, а исходные направления восстанавливаются из правых сингулярных векторов. Можно вычислять SVD матрицы с $g$ строками через взвешенные центры, что избавляет от матриц $p\times p$. Ранг $g-1$ ограничивает число ненулевых пар в разложении $P_B U$. Урезание исходного $X_T$ до $g-1$ компонент может потерять разделяющую информацию, как в контрпримере выше.

**Исследовательский вопрос книги.** Как получить разреженные обобщённые сингулярные векторы в исходных признаках, сохраняя информацию малой задачи? Восстановление $V\Sigma^{-1}z$ обычно уплотняет координаты.

### 7.4.2. Критерии распознавания образов

Печатные страницы 250–251. Авторы рассматривают $\operatorname{tr}(W_A^{-1}B_A)$ и $\det B_A/\det W_A$, где $W_A=A^\top W A$, $B_A=A^\top B A$. Эти критерии инвариантны к обратимой смене базиса внутри выбранного подпространства. Для положительно определённой $W_A$ первый суммирует, а второй перемножает обобщённые собственные значения сжатой пары. При фиксированном $A$ решаются системы размера $r$, без обращения полной $W$. Вырожденность $W_A$ остаётся возможной и при $A^\top A=I$.

Для критерия со следом, положив $M=W_A^{-1}$, получаем евклидов градиент $2(BA M-WA M B_A M)$. Его можно передать Manopt с фабрикой Штифеля. Для логарифма отношения определителей требуется также $B_A\succ0$. Логарифмический градиент вычисляется через системы с $B_A$ и $W_A$. У нулевого определителя исходный критерий может быть нулевым, а логарифм уже не определён.

### 7.4.3. LDA в нулевом пространстве

Печатные страницы 251–253. Сначала можно исключить $\ker T$ тонким SVD $X_T$, то есть записать $a=Vz$. Затем строят базис $P_0$ ядра $W_\pi=V^\top W V$. При $z=P_0c$ и $c^\top c=1$ критерий (7.35)–(7.36) превращается в максимум $c^\top P_0^\top V^\top B V P_0c$. Для нескольких направлений берут ведущие собственные векторы при ортонормированности $c$. Нормировка необходима для конечного максимума, а напечатанное отношение со знаменателем $a^\top W a$ в самом ядре использовать нельзя.

При $W=\operatorname{diag}(1,0,0)$ и $B=\operatorname{diag}(0,4,0)$ ось $e_2$ даёт ноль внутриклассового разброса, положительный межклассовый разброс и $\mu=1$. Ось $e_3$ лежит в общем ядре, давая $0/0$ даже при полной нормировке. Подстановка $W^\dagger$ превращает $W^\dagger B$ в ноль и скрывает первую ось. Один способ продолжить после нахождения информативных нулевых направлений — решать задачу для меньших значений $\mu$ в спектральном представлении §7.4.1. Условие $Wa\ne0$ само по себе не означает, что $a\in(\ker W)^\perp$.

### 7.4.4. LDA через общие главные компоненты, PLS и многомерное шкалирование

Печатные страницы 253–254. Модель общих главных компонент (CPC) допускает разные собственные значения внутриклассовых ковариаций при общих собственных направлениях. Пропорциональные ковариации — частный случай. Частичные наименьшие квадраты (PLS) дают другой способ работать с совместной изменчивостью данных и индикаторов классов. Метрика и нормировка определяют, когда такое сопоставление воспроизводит именно линейный дискриминантный анализ Фишера. Точную связь с CCA см. в [§8.6.1](30_mathematics/matrix-manifolds-manopt/chapters/mda-08-cca#861-cca-и-lda).

Классическое многомерное шкалирование центров классов по квадратам расстояний Махаланобиса воспроизводит геометрию центров после отбеливания общей ковариацией. При вырожденной матрице нужна явно выбранная замена метрики. Книга упоминает расстояния Хеллингера для модельных распределений с неодинаковыми ковариациями и отдельно предлагает исследовать матрицы расстояний между самими наблюдениями. **Исследовательский вопрос.** Какой выбор расстояния сохраняет интересующее разделение и остаётся устойчивым при малом числе наблюдений?

### 7.4.5. Разреженный LDA с диагональной матрицей разброса

Печатные страницы 254–255. В модели $W_d=\operatorname{Diag}(W)$ игнорируют корреляции внутри классов. При положительной диагонали отбеливание $Y=XW_d^{-1/2}$ заменяет задачу на поиск разреженных ведущих направлений межклассовой матрицы $Y$. Возврат $a=W_d^{-1/2}z$ сохраняет множество ненулевых индексов, так как меняет только масштаб каждой координаты. Нулевые диагональные элементы требуют явного решения о нулевой внутриклассовой дисперсии, например проверки разделения или введения положительной добавки.

Диагонализация способна изменить направление. При $W=\bigl(\begin{smallmatrix}2&1\\1&1\end{smallmatrix}\bigr)$ и $B=e_1e_1^\top$ получаем $W^{-1}e_1=(1,-1)^\top$, но $W_d^{-1}e_1=(1/2,0)^\top$. В плотной модели второй признак компенсирует внутриклассовую ковариацию, хотя его собственные средние по классам совпадают.

### 7.4.6. Разреженность с целевым значением критерия

Печатные страницы 255–256. Сначала вычисляют лучший плотный балл $d_0$. После диагонального отбеливания $M=W_d^{-1/2}BW_d^{-1/2}$ минимизируют $\|z\|_1+\tau(z^\top Mz-d_0)^2$ при единичной норме и исключении предыдущих осей. Штраф удерживает критерий около плотного эталона, пока первая часть уменьшает число существенных коэффициентов. Гладкая часть имеет градиент $4\tau(z^\top Mz-d_0)Mz$. Для реализации книга отсылает к Manopt в §4.8.4. Проверка алгоритма должна отдельно измерять разреженность, отклонение от $d_0$ и ошибку классификации.

Альтернативный критерий $\|z\|_1-\tau z^\top Mz$ проще и в опытах авторов быстрее, но меняет зависимость качества от настройки. В §7.4.6 также обсуждается вариант Witten–Tibshirani с ограничением $a^\top W_d a\le1$ и обычным или слитым LASSO. Слитый штраф добавляет цену соседних перепадов и имеет смысл, если признаки упорядочены содержательно.

### 7.4.7. Разреженная классификация по вероятности ошибки

Печатные страницы 256–258. Для двух нормальных классов с общей ковариацией $\Sigma$, равными априорными вероятностями и порогом посередине между центрами положим $d=(m_1-m_2)/2$. При $d^\top a>0$ вероятность ошибки равна $\Phi(-d^\top a/\sqrt{a^\top\Sigma a})$. В ROAD после нормировки $d^\top a=1$ минимизируют внутриклассовую дисперсию и добавляют штраф $\ell_1$ для выбора признаков. Книга выписывает варианты (7.41)–(7.42) с $T$. Для двух классов $B=\kappa dd^\top$, поэтому на точном ограничении $d^\top a=1$ имеем $a^\top Ta=a^\top Wa+\kappa$. В формуле самой вероятности ошибки знаменатель задаёт внутриклассовая ковариация, а при замене точного нормирования мягким штрафом добавка $\kappa(d^\top a)^2$ перестаёт быть константой. [Fan, Feng и Tong, исходная постановка ROAD](https://pmc.ncbi.nlm.nih.gov/articles/PMC3467977/)

Условие $\|a\|=1$ вместе с $d^\top a=1$ требует $\|d\|\ge1$. При $\|d\|<1$ можно перенастроить целевую величину проекции или выбрать иную нормировку. Двухклассовый пример Iris у авторов отделяет setosa от объединения двух остальных видов. Это другая задача, чем трёхклассовое сравнение §7.3.

### 7.4.8. Разреженный LDA через оптимальные оценки классов

Печатные страницы 258–259. Метод SLDA одновременно выбирает численные оценки классов $b\in\mathbb R^g$ и регрессию признаков на них. Критерий $\|Gb-Xa\|^2+\tau_1\|a\|_1+\tau_2\|a\|^2$ дополняют нормировкой $b^\top Nb/n=1$ и $N$-ортогональностью предыдущим контрастам, включая константу. При фиксированном $b$ получается регрессия с эластичной сеткой. При фиксированном $a$ находят нормированный допустимый контраст, ближайший к $Xa$.

Без штрафов и при фиксированном нормированном $b$ прогноз регрессии равен $P_{X_T}JGb$, где $P_{X_T}$ — ортогональный проектор на $\operatorname{col}X_T$. Подстановка в функцию потерь даёт максимум квадрата нормы такой проекции. Это формулировка через углы между столбцовыми пространствами центрированных $X$ и $G$. При классических условиях она даёт те же дискриминантные подпространства, что CCA и LDA Фишера. Положительный $\tau_2$ стабилизирует регрессионный блок при коллинеарности.

### 7.4.9. Многоклассовый разреженный дискриминантный анализ

Печатные страницы 259–260. Выделяют опорный класс и ищут направления $a_i$ для контрастов $d_i=m_1-m_i$. В (7.44) минимизируется $\sum_{i=2}^g(\tfrac12 a_i^\top T a_i-a_i^\top d_i)$ с возможным групповым штрафом $\sum_j\|(a_{2j},\ldots,a_{gj})\|_2$. При $T\succ0$ и нулевом штрафе условия оптимальности дают $Ta_i=d_i$. Групповой штраф выбирает признаки совместно для всех контрастов. При сингулярном $T$ и $d_i\in\operatorname{range}T$ решения без штрафа различаются добавками из ядра.

Переход от (7.44) к (7.46) в книге использует $Ta_i=d_i$, которое выполняется в оптимуме задачи без штрафа. До решения подставлять это равенство в свободную целевую функцию нельзя. При $T=\operatorname{diag}(4,1)$, $d=e_2$ минимум квадратичной функции даёт $a=e_2$, тогда как максимум $a^\top Ta$ на единичной сфере даёт $\pm e_1$ и теряет зависимость от контраста.

### 7.4.10. Разреженный LDA через обобщённую спектральную задачу

Печатные страницы 260–262. Для симметричной $U$ и $V\succ0$ обобщённая задача $Ua=\mu Va$ объединяет PCA с $(U,V)=(X_T^\top X_T,I)$, LDA с $(B,T)$ и CCA с составными матрицами из [§8.5.1](30_mathematics/matrix-manifolds-manopt/chapters/mda-08-cca#851-разреженная-обобщённая-спектральная-задача). В DC-GEV максимизируют $a^\top U a-\lambda\sum_j\log(\varepsilon+|a_j|)$ при $a^\top Va\le1$. Для локального выпуклого подшага квадратичную часть раскладывают как разность выпуклых функций с добавкой и вычитанием $t\|a\|^2$, $t\ge\max(0,-\lambda_{\min}(U))$. Вспомогательные $b_j\ge|a_j|$ дают возможность мажорировать вогнутый логарифм линейной касательной. Такая итерация даёт локальную оптимизацию, а глобальный максимум из неё не следует.

Для двух классов $B$ ранга один. Постановка DC-FDA (7.48) фиксирует $d^\top a=1$ и минимизирует $a^\top Ta+\lambda\sum_j\log(\varepsilon+|a_j|)$. При сингулярном $T$ ограничение $a^\top Ta\le1$ в общей версии само по себе не ограничивает длину в ядре. Для вычислений нужно явно обработать это ядро либо заменить метрику регуляризованной.

### 7.4.11. Структурная разреженность без штрафа

Печатные страницы 262–263. В SDP моделируют данные как $X\approx HXAA^\top$ с $A^\top A=I$ и максимум одним ненулевым элементом в каждой строке $A$. Запись $A=\operatorname{diag}(b)V$ кодирует величины в $b$ и назначения признаков столбцам в индикаторной матрице $V$. Для каждого столбца сумма квадратов назначенных ему $b_j$ должна равняться единице. При заданных назначениях ортогональность столбцов следует из непересечения их носителей.

Квадрат невязки равен $\|X\|_F^2-\|HX A\|_F^2$. После центрирования $HX=P_BX$, и максимизируемый вклад сводится к $\operatorname{tr}(A^\top BA)$. При фиксированных назначениях каждый столбец имеет собственную спектральную задачу в своём блоке признаков. Например, при $p=4$, $r=2$ и поддержках $\{1,2\}$, $\{3,4\}$ для каждого столбца требуется ведущий собственный вектор соответствующего блока $B$. Если в каждом признаке ровно одно ненулевое вхождение, число ненулевых элементов достигает $p$. При малом $r$ этого может оказаться недостаточно для отбора признаков.

## 7.5. Итоги

Печатные страницы 263–264. При полной $W$ основной переход — отбеливание и симметричная спектральная задача. При вырожденной $W$ нормировка по $T$ сохраняет разделяющие направления с нулевым внутриклассовым разбросом, а общее ядро исключают. Диагональная, регуляризованная и исходная метрики используют разную информацию о признаках. Разреженность может задаваться ограничением, штрафом или структурой носителей.

**Установленный перенос в машинное обучение.** При общей ковариации классов дискриминантное подпространство содержит все различия линейных байесовских баллов. Проекция на него может уменьшить размер входа классификатора. Для неодинаковых ковариаций различимость может идти только через разброс. Например, два одномерных нормальных класса с одинаковым средним и разными дисперсиями имеют $B=0$, хотя оптимальное правило по модулю отклонения способно различать классы.

## 7.6. Упражнения

Печатные страницы 264–268. Ниже разобраны задания 1–11. Для Manopt даны вычисляемые выражения и условия проверки. Исполнение MATLAB или Octave в рамках разбора не проверялось.

1. **Сложение разбросов.** Разложите $x_{ij}-\bar x=(x_{ij}-\bar x_i)+(\bar x_i-\bar x)$. Смешанные произведения исчезают после суммирования, поскольку $\sum_j(x_{ij}-\bar x_i)=0$. Остаются $W$ и $B$.
2. **Две группы.** Для $d=\bar x_1-\bar x_2$ имеем $B=(n_1n_2/n)dd^\top$. При $W\succ0$ и $d\ne0$ направления $W^{-1}d$ и $T^{-1}d$ пропорциональны. Действительно, $T\,W^{-1}d=[1+(n_1n_2/n)d^\top W^{-1}d]d$.
3. **Правило классификации.** При одинаковых дисперсиях и равных вероятностях выбираем ближайшее среднее. В нескольких измерениях при общей $\Sigma\succ0$ сравниваем $a^\top(x-m)$ с нулём, где $a=\Sigma^{-1}(\mu_1-\mu_2)$, $m=(\mu_1+\mu_2)/2$. При разных $\Sigma_i$ к классу 1 относим при $x^\top(\Sigma_1^{-1}-\Sigma_2^{-1})x-2x^\top(\Sigma_1^{-1}\mu_1-\Sigma_2^{-1}\mu_2)+c<0$, где $c=\log(\det\Sigma_1/\det\Sigma_2)+\mu_1^\top\Sigma_1^{-1}\mu_1-\mu_2^\top\Sigma_2^{-1}\mu_2$. Этот знак следует из разности удвоенных отрицательных логарифмов плотностей.
4. **Вариант Прокруста.** Используйте $X_B=P_BX$ и $X_W=(I-H)X$ с одинаковым числом строк. При фиксированном диагональном $D$ остаток $E=X_BA-X_WAD$ имеет градиент $X_B^\top E-X_W^\top ED^\top$ для половины квадрата нормы. При фиксированном $A$ коэффициент $d_j$ равен $\langle X_Wa_j,X_Ba_j\rangle/\|X_Wa_j\|^2$, если знаменатель положителен. С такими факторами числитель всегда нулевой из-за ортогональности проекторов. Поэтому (7.53) в буквальном выравнивании строк не воспроизводит LDA. Для связи с обобщённой спектральной задачей можно исследовать остаток $BA-WAD$ в пространстве признаков, дополнительно исключив тривиальные нулевые направления.
5. **Разреженный вариант (7.53).** Штраф или поколоночное ограничение $\|a_j\|_1\le\tau$ задаёт разреженность весов. Сначала следует проверить, что выбранные факторы и остаток действительно содержат дискриминантный сигнал, как показывает пункт 4.
6. **Разреженный GSVD.** **Исследовательское задание.** Наложите ограничение на исходный $a=V\Sigma^{-1}z$, затем сравните потерю $\mu$, число ненулей, устойчивость носителей и ошибки. Разреженность только в $z$ не обеспечивает разреженности $a$.
7. **Отношение следов.** Для $S_B=\operatorname{tr}(A^\top BA)$, $S_W=\operatorname{tr}(A^\top WA)>0$ градиент $S_B/S_W$ равен $2(BA-(S_B/S_W)WA)/S_W$. Для минимизации в Manopt передают отрицательное отношение и отрицательный градиент, например на $\mathrm{St}(p,r)$. В разреженном варианте добавляют покомпонентный $\ell_1$-штраф или его гладкую замену. При допустимом $S_W=0$ нужно отдельно учесть нулевое пространство или задать регуляризацию.
8. **Обобщённый спектральный критерий ранга один.** При $b\ne0$, $T\succ0$ и выбранном положительном знаке, положив $v=T^{-1}b$ и $c=b^\top v$, получаем $a_1=v/\sqrt c$ при $a_1^\top Ta_1=1$ и $a_2=v/c$ при $b^\top a_2=1$. Следовательно, $a_1=\sqrt c\,a_2$. У первого максимума допустим и противоположный знак.
9. **Логарифмическая аппроксимация.** Для $x\ge0$ функция $f_\varepsilon(x)=\log(1+x/\varepsilon)/\log(1+1/\varepsilon)$ стремится к $\mathbf1_{x>0}$ при $\varepsilon\downarrow0$ и к $x$ при $\varepsilon\to\infty$. По строгой вогнутости и росту при $0<x<1$ имеем $x<f_\varepsilon(x)<1$, при $x>1$ имеем $1<f_\varepsilon(x)<x$. Сумма по координатам даёт соответствующие приближения к числу ненулевых элементов и к $\ell_1$-норме.
10. **Центры в $K$-средних.** Согласованное произведение для формы $X\in\mathbb R^{n\times p}$ — $GC$, где $C\in\mathbb R^{g\times p}$. Нормальные уравнения $G^\top GC=G^\top X$ дают центры, а следующий шаг назначает строки ближайшим центрам. Пустой кластер требует отдельно определить его дальнейшую обработку.
11. **Сокращение размерности вместе с кластеризацией.** Для $F^\top F=I$ внутрикластерная матрица $W_F=F^\top(I-H)F=I-F^\top HF$. При фиксированном $G$ совместный критерий приводит к поиску ведущего центрированного подпространства для $XX^\top+H$ с весом при $H$, если он задан. При фиксированном $F$ обновляют $G$ методом $K$-средних. **Исследовательское задание.** Сравните устойчивость по начальным разбиениям и допустимые варианты кластерного индекса, с учётом возможной вырожденности $W_F$.

Для упражнения 7 при горизонтальных данных можно задать регуляризованную метрику $W_\eta=W+\eta I_p$, $\eta>0$. Тогда знаменатель на $\mathrm{St}(p,r)$ не меньше $\eta r$. Параметр $\eta$ определяет, насколько этот вариант меняет исходную задачу. В функции ниже $\tau=0$ даёт плотный вариант, $\tau>0$ добавляет сглаженный модуль. [Описание производных в Manopt](https://www.manopt.org/costdescription.html)

~~~matlab
function [A, value] = lda_trace_ratio(B, W, r, eta, tau, delta)
    p = size(B, 1);
    Wreg = W + eta*eye(p);
    problem.M = stiefelfactory(p, r);
    problem.cost = @cost;
    problem.egrad = @egrad;
    checkgradient(problem);
    [A, value] = conjugategradient(problem);

    function f = cost(A)
        ratio = trace(A'*B*A) / trace(A'*Wreg*A);
        penalty = sum(sqrt(A(:).^2 + delta^2) - delta);
        f = -ratio + tau*penalty;
    end

    function G = egrad(A)
        denominator = trace(A'*Wreg*A);
        ratio = trace(A'*B*A) / denominator;
        G = -2*(B*A - ratio*Wreg*A)/denominator ...
            + tau*A ./ sqrt(A.^2 + delta^2);
    end
end
~~~

Здесь $B$ и $W$ симметричны, $W\succeq0$, $1\le r\le p$, $\tau\ge0$, $\delta>0$. Сглаживание предназначено для дифференцируемого поиска. Ненулевые веса и значение исходного критерия после возможного отсечения проверяют отдельно.
