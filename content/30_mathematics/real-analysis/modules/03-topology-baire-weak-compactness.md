## Зачем нужен этот модуль

Продвинутый вещественный анализ объясняет, какие пределы, производные и линейные наблюдения остаются корректными вне конечномерной гладкой постановки.

## Центральный результат

Сильная топология контролирует норму, слабая — значения всех непрерывных линейных функционалов. [[30_mathematics/functional-analysis/theorems/baire-category|Теорема Бэра]] превращает полноту в принцип типичности, а [[30_mathematics/functional-analysis/theorems/banach-alaoglu|Банах—Алаоглу]] даёт слабую звёздную компактность двойственного шара.

Прямой метод строится по цепочке: ограниченность минимизирующей последовательности, слабая компактность, замкнутость допустимого множества и слабая полунепрерывность снизу.

## Схема доказательства

1. Пусть \((u_n)\) — минимизирующая последовательность для функционала \(J\) на допустимом множестве \(K\). Коэрцитивность \(J\) превращает ограниченность значений \(J(u_n)\) в ограниченность \((u_n)\) по норме.
2. В рефлексивном банаховом пространстве из ограниченной последовательности можно извлечь слабо сходящуюся подпоследовательность: \(u_{n_k}\rightharpoonup u\). Этот шаг опирается на слабую компактность замкнутого шара.
3. Если \(K\) слабо замкнуто, то предел \(u\) остаётся допустимым. Для выпуклого замкнутого множества слабая замкнутость следует из отделения точек функционалами.
4. Слабая полунепрерывность снизу даёт \(J(u)\le\liminf_kJ(u_{n_k})=\inf_KJ\). Следовательно, \(u\) — минимизатор. Без каждого из четырёх звеньев последовательность может уйти, предел — стать недопустимым, а значение — сделать скачок вниз.

## Что ломается

Слабая сходимость не гарантирует сходимость норм. Компактность в слабой звёздной топологии не следует путать с компактностью по норме или последовательностной компактностью без дополнительных условий.
