# Теорема Фабера–Бернштейна о расходимости интерполяции

## Зачем нужен отрицательный результат

Можно выбрать узлы разумно, но нельзя построить последовательность интерполяционных сеток, которая равномерно работает для всех непрерывных функций. Теорема отделяет универсальные обещания от гарантий на ограниченных классах гладкости.

## Формулировка

Для любой последовательности простых сеток на $[a,b]$ существует функция $f\in C[a,b]$, для которой последовательность интерполяционных полиномов не сходится равномерно ни к какой непрерывной функции.

## Доказательство — функционально-аналитическая схема

1. Каждая сетка задаёт линейный непрерывный проектор $P_n:C[a,b]\to\mathcal P_n$.

2. Если бы $P_nf$ сходился равномерно для каждого $f\in C[a,b]$, то для каждого фиксированного $f$ последовательность $\{\|P_nf\|\}$ была бы ограничена.

3. [[30_mathematics/functional-analysis/theorems/uniform-boundedness|Принцип равномерной ограниченности]] тогда дал бы

   $$
   \sup_n\|P_n\|<\infty.
   $$

4. Однако нормы интерполяционных проекторов не могут оставаться ограниченными. В доказательстве источника алгебраический проектор связывается с тригонометрическим, а его усреднение — с частичной суммой ряда Фурье. Норма последней растёт не медленнее $c\log n$.

5. Значит, $\sup_n\|P_n\|=\infty$. По контрапозиции принципа равномерной ограниченности существует непрерывная функция, для которой $\{P_nf\}$ неограничена и потому не может сходиться равномерно.

## Понятный образ

Проектор работает как усилитель ошибок данных. Для каждой конкретной функции усиление может долго быть незаметным, но если коэффициент усиления системы неограниченно растёт, найдётся входной сигнал, который его проявит.

## Контрпример к слишком сильному выводу

Теорема не утверждает, что интерполяция всегда расходится. Для полинома фиксированной степени она с некоторого номера точна, а для аналитических функций на чебышёвских сетках ошибка убывает геометрически.

Функция Бернштейна $f(x)=|x|$ показывает более конкретный сбой равномерных сеток: соответствующие интерполяционные полиномы расходятся почти во всех точках.

## Вычислительный эксперимент

Стройте графики константы Лебега для равномерных и чебышёвских сеток. Затем сравните функцию Рунге, $|x|$ и аналитическую функцию без близких особенностей. Один график нормы проектора не заменяет анализ класса функций.

## Перенос в ИИ

**Установленный результат.** Теорема относится к линейным интерполяционным проекторам в $C[a,b]$.

**Аналогия.** Не существует универсальной схемы размещения обучающих точек, которая одна без предположений о целевой функции гарантирует хорошую реконструкцию.

**Граница переноса.** Теорема не является доказательством невозможности обучения нейронных сетей: архитектура, регуляризация, распределение данных и целевой класс принципиально другие.
