# Восстановление матрицы → проверка рекомендаций на скрытых наблюдениях

## Какая структура сохраняется

Пусть строки матрицы соответствуют пользователям, столбцы — объектам, а множество $\Omega$ содержит известные оценки. В факторной модели предсказание имеет вид $\widehat M_{ij}=u_i^Tv_j$. Низкий ранг связывает разные ячейки общими факторами. Маска задаётся индексами наблюдений: оценка, равная нулю, остаётся наблюдением; отсутствие оценки не становится нулевой оценкой.

Разделим известные наблюдения на попарно непересекающиеся множества $\Omega_{\mathrm{train}}$, $\Omega_{\mathrm{val}}$ и $\Omega_{\mathrm{test}}$. Например, регуляризованная обучающая задача имеет вид

$$
\min_X\;\frac12\|P_{\Omega_{\mathrm{train}}}(X-M)\|_F^2+\lambda\|X\|_*.
$$

Оператор $P_\Omega$ сохраняет элементы с индексами из $\Omega$ и обнуляет остальные. Его нули вне маски служат способом записи функции, а не новыми наблюдениями. Факторная задача с заданной размерностью решает другую оптимизационную постановку; её нельзя автоматически наделять гарантиями выпуклой задачи с ядерной нормой.

> [!established] Установлено
> При непересекающихся масках проверочные значения не входят в выписанную обучающую функцию. Это утверждение о зависимости вычислений от данных. Оно само по себе не доказывает, что алгоритм хорошо предсказывает неизвестные оценки.

## Почему известные ячейки не подтверждают заполнение

Для любого ненулевого $a$ матрица

$$
M(a)=\begin{pmatrix}1&a\\a^{-1}&1\end{pmatrix}
$$

имеет ранг один и одинаковую диагональ. Если наблюдается только диагональ, обучающая ошибка каждой такой матрицы равна нулю, хотя неизвестные элементы различаются. Низкий ранг и точное согласие с наблюдениями не выбирают истинный параметр $a$.

[[30_mathematics/big-data-algorithms/theorems/bda-matrix-completion-identifiability|Теорема для ранга один]] объясняет роль связности графа при ненулевых факторах. При большем ранге одна связность не даёт аналогичной гарантии. Регуляризация выбирает решение согласно дополнительному предпочтению; выбор не превращается в доказательство истинности заполнения.

## Проверочный протокол

1. Зафиксировать правило разделения до обучения. Сохранить сами маски, порядок данных и начальное состояние генератора случайных чисел.
2. Рассчитать средние, масштабы и другие преобразования только по обучающим наблюдениям. Исключённые значения нельзя использовать даже для первоначального заполнения.
3. Обучить модель по $\Omega_{\mathrm{train}}$. Выбирать ранг, штраф и остановку по $\Omega_{\mathrm{val}}$, сохраняя историю выбора.
4. После выбора параметров один раз оценить ошибку на $\Omega_{\mathrm{test}}$. Если тестовые значения уже участвовали в настройке, это множество больше не служит независимой итоговой проверкой.

Для непустой проверочной маски можно вычислить

$$
\operatorname{RMSE}_{\mathrm{val}}=
\sqrt{\frac1{|\Omega_{\mathrm{val}}|}
\sum_{(i,j)\in\Omega_{\mathrm{val}}}(\widehat M_{ij}-M_{ij})^2}.
$$

При пустой маске эта величина не определена. Число известных оценок и состав пользователей нужно сообщать вместе с ошибкой. Пользователь или объект без обучающих наблюдений не получает факторы из этой функции потерь; решение для него требует отдельно заданного начального состояния, штрафа либо дополнительных признаков. Это случай холодного старта, который средняя ошибка по остальным наблюдениям может скрыть.

## Механизм пропусков ограничивает вывод

Пользователи обычно выбирают, какие объекты оценивать. Поэтому случайное исключение части уже известных оценок проверяет предсказания внутри распределения известных оценок; оно не воспроизводит автоматически распределение всех неизвестных предпочтений. Временное разделение проверяет другой вопрос — предсказание последующих взаимодействий. Разделение по новым пользователям проверяет холодный старт. Эти протоколы не взаимозаменяемы.

> [!research-hypothesis] Гипотеза исследования
> Низкоранговая модель может предсказывать скрытые оценки лучше выбранной базовой модели. Гипотезу проверяют на заранее определённом разделении и механизме пропусков. Вероятностная теорема для равномерной случайной маски не устанавливает эту пользу для реальных пользовательских данных.

На схеме оранжевые ячейки обозначают отложенные известные оценки. Пустые ячейки остаются неизвестными: их истинные значения не используются ни в обучении, ни в показанной оценке ошибки. Схема описывает протокол, а не обещанное качество модели.

## Самопроверка

1. Почему нельзя искать наблюдения условием $M_{ij}\ne0$? Оно теряет наблюдаемые нули и смешивает значения с маской.
2. Достаточно ли исключить проверочные ячейки из последней функции потерь? Нет: их значения могли попасть в первоначальное заполнение, преобразования или настройку параметров.
3. Доказывает ли нулевая обучающая ошибка правильность пропусков? Нет: семейство $M(a)$ даёт явный контрпример.
4. Что проверяет случайная часть известных оценок? Качество на выбранном распределении известных оценок, при сохранении принятых условий разделения.
