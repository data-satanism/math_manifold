# Графические ядра → структурный вывод в ИИ

## Математическая структура переноса

Перенос сохраняет не слово «граф», а точную цепочку:

$$
f(x,y)=\sum_c f_c(x_c,y_c)
\Longrightarrow
p(y\mid x)\propto\prod_c e^{f_c(x_c,y_c)}
\Longrightarrow
k((x,y),(x',y'))=\sum_{c,d}k_{cd}
\Longrightarrow
\text{локальные сообщения}.
$$

Локальная аддитивность оценки одновременно определяет вероятностную факторизацию, допустимую форму RKHS и алгоритм вывода. Нельзя сохранить только внешний рисунок графа, отбросив эти три соответствия.

## Интуитивный перенос

Представим сложный ответ как проект, который собирают локальные команды. Каждая команда видит свою клику переменных, а соседние команды согласуют общие компоненты через интерфейс-разделитель.

Точное соответствие:

| Образ | Математический объект |
|---|---|
| локальная команда | клика $c$ |
| локальная оценка проекта | потенциал $f_c$ |
| общий интерфейс | разделитель клик |
| сводка соседу | сообщение $m_{a\to b}$ |
| размер интерфейса | показатель стоимости $q^{w+1}$ |
| согласованный проект | глобальная структура $y$ |

Аналогия перестаёт работать, если команды имеют скрытые глобальные зависимости: тогда сумма локальных оценок не описывает настоящую функцию.

## ИИ: механизм и проверка

### Разметка последовательностей

**`established` — установленный результат.** Для цепочки оценка складывается из признаков наблюдения и переходов соседних меток. Алгоритм вперёд—назад вычисляет нормировку и маргиналы, а Витерби — наиболее вероятную последовательность.

Проверяемые величины:

- сумма маргинальных вероятностей в каждой позиции равна единице;
- соседние парные и одномерные маргиналы согласованы;
- динамическое программирование совпадает с полным перебором на короткой последовательности.

### Структурный метод опорных векторов

**`established` — установленный результат при точном оракуле.** Та же локальная оценка позволяет искать наиболее нарушающего конкурента динамическим программированием и использовать [[30_mathematics/kernel-methods/theorems/constraint-generation-epsilon-guarantee|метод рабочего множества]]. Вероятностная нормировка здесь не нужна, но графическая декомпозиция сохраняется.

### Современные гибридные модели

**`analogy` — аналогия.** Выход нейронной сети можно использовать как локальные потенциалы, после чего структурный слой согласует метки. Теорема о ядрах не распространяется автоматически на обучаемую нейронную часть.

**`research hypothesis` — исследовательская гипотеза.** Сочетание обучаемого представления с положительно определёнными кликовыми ядрами может дать контролируемый локальный слой сходства. Проверять следует калибровку, спектр матрицы Грама и выигрыш относительно модели без структурного ограничения.

## Что перенос не сохраняет

- Локальная факторизация не означает независимое предсказание компонент.
- MAP-структура не содержит полную информацию о неопределённости.
- Совместимость ядра с графом не гарантирует малую древесную ширину.
- Приближённая передача сообщений не наследует точность дерева сочленений.
- Граф, заданный экспертом, может исключить важную дальнюю зависимость.

## Практический протокол

1. Выбрать переменные, клики и предполагаемые условные независимости.
2. Проверить, что оценка действительно складывается из кликовых членов.
3. Сконструировать полное положительно определённое ядро из локальных блоков.
4. Оценить древесную ширину и выбрать точный или приближённый вывод.
5. На малых задачах сравнить сообщения с полным перебором.
6. Для вероятностной модели проверить нормировку, согласованность маргиналов и калибровку.
7. Для отступной модели проверить максимальное нарушение и точность оракула.

## Режимы отказа

- нулевые вероятности используются без учёта границы теоремы Хаммерсли—Клиффорда;
- сумма эвристических блоков даёт неопределённую матрицу Грама;
- большая древесная ширина скрыта за визуально разреженным графом;
- приближённые маргиналы объявлены точными;
- структурное смещение ухудшает результат из-за неверного графа.
