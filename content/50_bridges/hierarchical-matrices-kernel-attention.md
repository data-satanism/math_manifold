# Иерархические матрицы → быстрые ядровые взаимодействия и внимание

## Математическая структура

Геометрически близкие взаимодействия хранятся подробно, а хорошо разделённые группы с гладким ядром заменяются малоранговыми блоками. Выигрыш возникает из разделимости функции взаимодействия, а не из плотности матрицы как таковой.

Структура, которую можно переносить, состоит из трёх частей: иерархической кластеризации индексов, критерия допустимости дальнего блока и апостериорного контроля

$$
\frac{\|A_{ST}-U_{ST}V_{ST}^T\|}{\|A_{ST}\|}\le\varepsilon.
$$

Для матрицы внимания каждая часть должна быть построена заново в геометрии признаков. Порядок токенов сам по себе не задаёт физического расстояния, а мягкая нормализация строк может менять ранги блоков.

## Уровни утверждений

**Установлено.** Для разделимых дальних взаимодействий и сбалансированного дерева иерархическое хранение может иметь порядок $O(n\log n)$.

**Установлено.** Крестовая аппроксимация восстанавливает низкоранговый блок по выбранным строкам и столбцам при устойчивом опорном пересечении.

**Аналогия.** Дальние зависимости в механизме внимания можно группировать и сжимать, сохраняя локальные взаимодействия подробно.

**Ограничение.** Семантическая близость не обязана совпадать с геометрией индексов, а матрица внимания не обязана быть малоранговой.

**Исследовательская гипотеза.** Адаптивная допустимость блоков по наблюдаемому спаду сингулярных чисел надёжнее фиксированного окна.

## Проверка

Для каждого уровня измеряйте ранги блоков, норму остатка, память, время построения и итоговую ошибку модели. Отдельно проверяйте редкие дальние события.

Стратифицируйте тесты по локальным, типичным дальним и редким дальним парам. Средняя норма ошибки может скрыть одиночное семантически важное взаимодействие, которое исчезает после сжатия.

### Как читать рисунок

Слева геометрия строится в пространстве признаков, а не по соседству индексов. В центре иерархическая перестановка обнаруживает плотные локальные и потенциально малоранговые дальние блоки; решение о сжатии подтверждают спектр и остаток. Справа строгий результат для гладкого разделимого ядра отделён от аналогии с вниманием. Нижний пример показывает редкую дальнюю пару, которая делает спектр блока плоским и исчезает при грубом сжатии.
