# Случайные проекции → сжатие геометрии и поиск похожих объектов

## Математическая структура

Пусть $X=\{x_1,\ldots,x_N\}\subset\mathbb R^n$ — заранее фиксированный конечный набор. Случайная проекция

$$
Q\colon\mathbb R^n\to\mathbb R^m
$$

при

$$
m\gtrsim\varepsilon^{-2}\log N
$$

может с высокой вероятностью сохранить все попарные расстояния:

$$
(1-\varepsilon)\|x_i-x_j\|_2
\le
\|Qx_i-Qx_j\|_2
\le
(1+\varepsilon)\|x_i-x_j\|_2.
$$

Механизм:

$$
\boxed{\text{концентрация одной длины}}
\rightarrow
\boxed{\text{не более }N^2\text{ пар}}
\rightarrow
\boxed{\text{объединяющая оценка}}.
$$

## Интуитивный перенос: складская карта

Представим большой склад, где кратчайшие маршруты между выбранными пунктами уже известны. Нам нужна компактная двумерная схема не всего здания, а только этих пунктов. Если схема почти сохраняет расстояния между каждой парой, она пригодна для маршрутизации по заданному каталогу, даже если не передаёт всю геометрию склада.

Это **`analogy`**: случайная проекция сохраняет конечное семейство расстояний, а не произвольную семантику.

## Перенос в ИИ

### Установленный результат

Для фиксированного набора евклидовых представлений лемма Джонсона—Линденштрауса даёт вероятностную гарантию сохранения попарных расстояний после случайного линейного сжатия. Это **`established`**.

### Следствие для поиска

Если решение о ближайшем соседе имеет запас

$$
\|q-x_{(2)}\|_2
>
\frac{1+\varepsilon}{1-\varepsilon}
\|q-x_{(1)}\|_2,
$$

то искажение в пределах $(1\pm\varepsilon)$ не меняет победителя. Без запаса даже малое искажение может переставить почти равных соседей.

### Аналогия

Сжатое пространство — не «понимание смысла», а геометрический эскиз (sketch) фиксированного набора. Это **`analogy`**.

### Исследовательская гипотеза

Адаптивный выбор размерности по профилю запасов ближайших соседей может уменьшать стоимость индекса без заметной потери качества. Это **`research hypothesis`** и требует проверки на конкретных данных и запросах.

## Практический протокол

1. Зафиксировать набор документов и контрольных запросов до генерации проекции.
2. Оценить распределение относительного искажения расстояний.
3. Измерить не только среднее искажение, но и долю смен ближайшего соседа.
4. Стратифицировать ошибки по малому и большому запасу.
5. Повторить эксперимент для нескольких случайных матриц.

## Режимы отказа

- **Адаптивный набор.** Точки добавляются после выбора проекции в направлении её ядра.
- **Неподходящая метрика.** Качество задачи определяется косинусом или иной метрикой, а проверяется евклидово расстояние без нормировки.
- **Малый запас.** Два кандидата почти равноудалены.
- **Семантический разрыв.** Геометрия исходных представлений уже не соответствует целевой релевантности.

## Вычислительный эксперимент

```python
import numpy as np

rng = np.random.default_rng(61)
N, n, m = 1500, 768, 160
X = rng.normal(size=(N, n))
X /= np.linalg.norm(X, axis=1, keepdims=True)
Q = rng.normal(size=(m, n)) / np.sqrt(m)
Y = X @ Q.T

pairs = rng.integers(0, N, size=(10_000, 2))
d0 = np.linalg.norm(X[pairs[:, 0]] - X[pairs[:, 1]], axis=1)
d1 = np.linalg.norm(Y[pairs[:, 0]] - Y[pairs[:, 1]], axis=1)
rel = d1 / d0
print(np.quantile(rel, [0.01, 0.5, 0.99]))
```
