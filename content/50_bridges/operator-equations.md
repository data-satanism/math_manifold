# Операторные уравнения → обратные задачи и регуляризация

## Прямая и обратная задачи

Прямая модель $A:X\to Y$ предсказывает измерение $b=Ax+\eta$. Обратный метод восстанавливает $x$ по $b$. Если $A^{-1}$ неограничен, шум усиливается сколь угодно сильно.

## Установленный результат: спектральная картина

Для компактного оператора сингулярная система даёт

$$
b=\sum_k \sigma_k\langle x,v_k\rangle u_k+\eta.
$$

При $\sigma_k\to0$ наивное обращение умножает шум на $1/\sigma_k$. Регуляризатор вводит фильтр $g_\lambda(\sigma)$, подавляющий неустойчивые компоненты.

## Архитектура из трёх частей

Надёжный обучаемый метод обращения следует разложить на:

1. **согласование с данными:** соответствие физическому измерению;
2. **априорное ограничение и регуляризатор:** допустимая структура решения;
3. **решатель:** алгоритм и правило остановки.

Сквозная сеть может скрывать все части, но проверка должна разделять их влияние.

## Обучаемые регуляризаторы

- Метод подстановки подавителя шума (plug-and-play) использует его внутри итерационной схемы.
- Развёрнутые сети обучают шаги и параметры конечного решателя.
- Методы обращения на основе функции оценки объединяют градиент правдоподобия и априорную оценку.
- Обучение операторов приближает прямой оператор решения для семейства задач.

Гарантии требуют предположений о усреднённости, контроле Липшица, согласованности или корректности апостериорного распределения; они не следуют из хорошего значения PSNR.

## Протокол проверки

1. Метрика восстановления на данных из распределения обучения.
2. Согласованность измерений $\|A\hat x-b\|$.
3. Кривая ошибки при изменении уровня шума.
4. Работа при параметрах прямой модели вне распределения обучения.
5. Проверка галлюцинаций в ядре оператора.
6. Базовые методы: регуляризация Тихонова, усечённое SVD и классический итерационный решатель.

## Исследовательская гипотеза

Спектральная диагностика может выбирать силу регуляризации или глубину развёртывания адаптивно. Проверка требует отложенных операторов, а не только отложенных измерений одного $A$.
