# Подпространства Крылова → матрично-свободные шаги второго порядка

## Математическое ядро

Ньютоновская подзадача имеет вид $Hs=-g$. Если можно вычислять $Hv$, подпространство

$$
\mathcal K_k(H,g)=\operatorname{span}\{g,Hg,\ldots,H^{k-1}g\}
$$

позволяет найти приближённый шаг без явного хранения $H$.

## Понятный образ

Полный гессиан — огромная карта всех локальных кривизн. Крыловский метод не рисует карту целиком: он посылает несколько пробных направлений, наблюдает ответ кривизны и строит малую карту только в реально посещённых направлениях.

## Уровни утверждений

**Установлено.** Для положительно определённого $H$ метод сопряжённых градиентов минимизирует энергетическую ошибку на крыловском подпространстве.

**Установлено.** Процесс Арнольди или Ланцоша строит ортонормированный базис и малую проекцию оператора из последовательности произведений на вектор.

**Аналогия.** Малая проекция действует как адаптивная модель кривизны, сосредоточенная на текущем градиенте.

**Исследовательская гипотеза.** Числа Ритца могут служить сигналом для выбора размера внутреннего подпространства или обновления предобусловливателя.

## Практический протокол

1. Реализуйте проверяемое действие $v\mapsto Hv$.
2. Определите, симметрична ли фактическая линейная подзадача.
3. Выберите решатель: сопряжённые градиенты для положительно определённой формы, минимальные невязки для общей.
4. Согласуйте внутренний допуск с внешним шагом.
5. Контролируйте отрицательную кривизну и качество предобусловливания.

## Возможные сбои

- гессиан неопределён, а выбран метод для положительно определённых матриц;
- произведения на вектор вычисляются неточно или несогласованно;
- слишком точное внутреннее решение тратит работу, когда локальная модель уже устарела;
- малая невязка линейной системы не гарантирует хороший внешний шаг без глобализации.
