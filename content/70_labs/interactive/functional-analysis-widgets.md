## Accessibility checklist

- Controls имеют labels и управляются клавиатурой.
- Canvas снабжён `aria-label`.
- Цвет не является единственным носителем смысла.
- При отключённом JavaScript показывается SVG fallback.
- Layout перестраивается на узком экране.
