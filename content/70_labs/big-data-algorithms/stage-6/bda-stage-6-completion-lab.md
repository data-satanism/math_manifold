# Лаборатория этапа 6. Маска, однозначность и отложенные наблюдения

Проверяются математические механизмы [[30_mathematics/big-data-algorithms/modules/bda-05-matrix-completion|блока 05]] и [[30_mathematics/big-data-algorithms/theorems/bda-matrix-completion-identifiability|графовой теоремы ранга один]]. Примеры различают совпадение с наблюдениями, однозначность, оптимизацию регуляризованной функции и качество на отложенных значениях. Опыт малый и синтетический; он не проверяет асимптотическую теорему Candès–Recht или скорость промышленной реализации.

## Запуск и воспроизводимость

Из корня авторского хранилища:

```powershell
python -B 70_labs/big-data-algorithms/stage-6/run_completion_checks.py
```

Проверенное окружение: Python 3.10.0, NumPy 1.26.4, matplotlib 3.8.2. Используются `float64`, `numpy.random.default_rng(20261002)`, плотное точное SVD малых матриц и шаг $t=1$. Предел числа проксимальных шагов — 4000. Остановка наступает, когда норма разности очередного шага, делённая на $t$, не выше $2\cdot10^{-8}\max(1,\|X\|_F)$. Это практический относительный допуск, а не заявленная ошибка заполнения. Потоки BLAS ограничиваются переменными среды до загрузки NumPy; последние биты могут зависеть от библиотеки BLAS.

Сценарий сохраняет:

- `70_labs/big-data-algorithms/stage-6/completion-results.json` — все исходные малые матрицы, булевы маски, параметры, версии, SHA256 сценария и PDF, история целей, остатки шагов и именованные проверки;
- `70_labs/big-data-algorithms/stage-6/completion-results.csv` — исходы проверок и их измерения;
- `80_assets/big-data-algorithms/plots-stage6-v1/bda-05-matrix-completion.svg` — воспроизводимый вычислительный рисунок;
- `70_labs/big-data-algorithms/stage-6/completion-figure-preview.png` — просмотр того же рисунка для визуальной проверки.

Сценарий не устанавливает пакеты и не меняет PDF или Markdown. Проверка происхождения явно требует наличия трёх источников: исходного Han-Chen и двух приватных первичных PDF. Их SHA256 сравниваются до и после вычислений. Без исходного файла математические расчёты остаются возможны, но соответствующая проверка происхождения не проходит; отсутствие PDF не считается подтверждённой сохранностью. Имена и хеши записаны в JSON; приватные копии и абсолютные пути не экспортируются в учебный текст.

График строится после сохранения и повторного чтения JSON. Его можно заново получить без вычисления опыта:

```powershell
python -B 70_labs/big-data-algorithms/stage-6/run_completion_checks.py --plots-only
```

SVG не содержит текущей даты и использует постоянный `svg.hashsalt`. Повторное построение по одному JSON сохраняет одинаковый файл. Повторный полный запуск обновляет только названные вычислительные результаты и рисунок этого этапа.

## Что проверяется

| Группа | Независимый контроль | Условие и ожидаемый отказ |
| --- | --- | --- |
| Маска | Идемпотентность, линейность, самосопряжённость, конечность известных значений | Известный ноль остаётся наблюдением; целочисленная маска, неверный размер и известный `NaN` отклоняются |
| Ранг один | Обход связной маски восстанавливает $\left(\begin{smallmatrix}1&2\\0.5&1\end{smallmatrix}\right)$ | Ненулевые наблюдения; несовместимый цикл отклоняется |
| Неоднозначность | 61 значение $a\in[0.25,4]$ для диагонального семейства | Все матрицы ранга один имеют одинаковые диагональные наблюдения, разные пропуски |
| Нулевые значения | Две матрицы $\left(\begin{smallmatrix}0&0\\0&a\end{smallmatrix}\right)$ | Связность при нулевых рёбрах не обеспечивает единственность |
| Ранг и ядерная норма | Сравниваются $I_2$ и матрица из единиц; связный пример с последним элементом $9$ или $1$ | Ядерный минимум не обязан выбирать единственное заполнение ранга один |
| Одно SVD | Усечённое разложение после нулевого заполнения | Меняет известные значения: RMSE по обучению $0.227668$, неизвестное значение $0.206010$ вместо $1$ |
| Проксимальный шаг | Спектральный порог на диагональном примере, численная производная маскированной функции | Проверка градиента не использует неизвестные значения; слишком большой шаг увеличивает скалярную цель |
| Семь штрафов | Значение $F_\lambda$, остаток шага и явная остановка | Убывание сравнивается с допуском $2\cdot10^{-10}\max(1,F_\lambda(X^0))$ |
| Утечка ответов | Все значения вне обучения заменяются огромными числами, затем повторяются расчёты | Средние, масштабы и все семь обученных матриц должны совпасть |
| Разбиение | Три маски не пересекаются; обучающий граф связен, каждая строка и столбец представлены | Не моделируется новый пользователь без наблюдений |
| ALS | Проверяется убывание после каждого обновления целого блока | При положительном штрафе; нулевой старт остаётся в неподходящей стационарной точке |
| Происхождение | SHA256 трёх PDF до и после, наличие всех файлов | Источник не изменяется, пропавший файл не пропускается молча |

Основной допуск сравнения массивов — $2\cdot10^{-10}\max(1,\|\text{эталон}\|)$, для центральной численной производной — $10^{-8}$ с такой же нормировкой. Это допуски конкретных малых расчётов в `float64`.

Отрицательный контроль имеет `passed: true`, когда заранее указанный отказ **обнаружен**. Так, нулевой старт ALS на матрице из единиц даёт цель $2$, а явно допустимые ненулевые факторы — $0.2$. Убывание блочных целей не принимается за доказательство глобального минимума. Для пустой строки отдельная проверка получает нулевой фактор из штрафа; это не восстановление неизвестных предпочтений.

## Зашумлённая задача и выбор штрафа

Матрица $M=LR^T/\sqrt2$ имеет размер $18\times16$ и ранг $2$; $L,R$ — фиксированно сгенерированные гауссовские факторы. Наблюдаемые значения равны $Y=M+\varepsilon$, шум имеет стандартное отклонение $0.2$. Распределение масок — одна фиксированная случайная реализация:

- обучение — 168 позиций;
- выбор параметра — 58 позиций;
- окончательный контроль — 25 позиций;
- остальные 37 позиций не используются как наблюдения.

До обучения определена сетка $\lambda/\lambda_{\max}\in\{0,0.005,0.02,0.05,0.12,0.25,1.05\}$, где $\lambda_{\max}=\|P_{\Omega_{\mathrm{train}}}Y\|_2\approx8.458211$. При $\lambda\ge\lambda_{\max}$ нулевая матрица является минимумом: для произвольного $X$ двойственность норм даёт

$$
F_\lambda(X)-F_\lambda(0)
=\tfrac12\|P_{\Omega_{\mathrm{train}}}X\|_F^2
-\langle P_{\Omega_{\mathrm{train}}}Y,X\rangle_F+\lambda\|X\|_*
\ge(\lambda-\lambda_{\max})\|X\|_*\ge0.
$$

Наибольший проверенный параметр равен $1.05\lambda_{\max}$; сценарий получает нулевое решение. При $\lambda=0$, напротив, наблюдаемая невязка практически нулевая, а пропуски остаются нулями — это оптимизация без нужного структурного выбора.

Проверочная RMSE выбирает индекс 4, то есть $\lambda=0.12\lambda_{\max}\approx1.014985$. После выбора контрольная RMSE вычисляется **только для одной** выбранной модели. Полная матрица сгенерирована и записана для воспроизводимости, но решатель, статистики и выбор параметра её скрытые ответы не читают.

| Результат | Значение | Что означает |
| --- | --- | --- |
| Обучающая RMSE выбранной модели | $0.208608$ | Совпадение с использованными зашумлёнными ответами |
| Проверочная RMSE выбранной модели | $0.424208$ | Критерий выбора на фиксированной сетке; уже использован для настройки |
| Окончательная контрольная RMSE | $0.254976$ | Один контроль после выбора, всего по 25 позициям |
| Проверочная RMSE при $\lambda=0$ | $1.172339$ | Интерполяция обучения не предсказывает скрытые значения |
| Ранг выбранной матрицы при допуске $10^{-7}$ | $4$ | Численный ранг оценки, не истинный ранг сигнала $2$ |
| Число шагов выбранной модели | $127$ | Остановка конкретного малого плотного решателя |
| Окончательная норма остатка шага | $2.53675\cdot10^{-7}$ | Абсолютная норма; относительный допуск использует норму матрицы |

RMSE здесь сравнивает предсказания с зашумлёнными $Y$, а не с истинной $M$. Величины разных масок могут различаться случайно. Меньшая контрольная ошибка не означает более лёгкую популяцию или надёжное превосходство метода: окончательное множество очень мало. Сценарий не вычисляет контрольную кривую для семи моделей, чтобы не использовать контроль для настройки.

## Сохранённый результат и рисунок

Основной запуск проходит **197 именованных проверок**. В это число входят 122 проверки ранга и наблюдений для 61 члена **одного** семейства, проверки семи моделей и другие малые контроли. Это не 197 независимых экспериментов и не 197 математических доказательств. Исходы, допуски и измерения сохранены в JSON/CSV; SHA256 сценария должен соответствовать текущему коду.

В левой панели ошибки вычислены относительно матрицы из единиц, выбранной как один из возможных истинных объектов; диагональ не позволяет предпочесть её остальным. В средней панели показана **сама** $F_\lambda$, а не разность с неизвестным точным минимумом. В правой панели значения сетки равномерно размещены как отдельные категории: расстояние по горизонтали не кодирует расстояние между значениями $\lambda$.

**Установлено (`established`).** Опыт проверяет корректность маскированного градиента, предписанного спектрального шага, независимость обучения от скрытых ответов и указанные алгебраические отказы.

**Исследовательская гипотеза (`research hypothesis`).** Выигрыш регуляризации на реальных пропусках требует отдельного протокола. Ни одна малочисленная случайная маска не подтверждает качество для будущих пользователей, систематических пропусков или изменения распределения.
