# Воспроизводимая лаборатория рангов и спектра

Лаборатория проверяет конечномерные механизмы на заданных матрицах. В каждом опыте нужно различать доказанное равенство, численную проверку и используемый порог ранга. Скрипт строит 14 научных SVG и сохраняет значения для повторной сверки.

## Запуск

Из корня авторского хранилища с установленными Python, NumPy и Matplotlib выполните

```powershell
python 70_labs/computational-algebra-principles/rank_spectrum_lab.py
```

Вычисления записаны в файле rank_spectrum_lab.py, построение панелей — в rank_spectrum_figures.py. Источники находятся рядом с этой заметкой. В опытах нет случайных выборок. Ранг для численной сверки считается по относительному порогу $10^{-11}\sigma_1$. Этот порог нужен для контроля округления и не заменяет доказательств точного ранга.

## Контрольные результаты

| --- | --- | --- |

| Неотрицательный ранг | Циклический носитель $4\times4$ | Обычный ранг 3 и точный сертификат четырёх компонент |
| Матрица Коши | 48 узлов на каждом из двух интервалов | $\sigma_2/\sigma_1\approx0{,}01026$. Для степеней от 1 до 7 проверены ранг поправки и верхняя граница |
| CP и TT | $X_{ijkl}=\delta_{ik}\delta_{jl}$, $n=4$ | Канонический ранг 16, два порядка TT требуют 544 и 64 числа |
| QTT | 8 бит, синус и равенство битовых половин | У синуса ранги до 2. Для равенства два порядка дают максимумы 16 и 2 |
| Квадратура | Синус суммы, 5 осей, 11 узлов трапеций | Прямая сумма $0{,}4830467080$, свёртка совпадает до $4{,}5\cdot10^{-16}$. Ошибка относительно интеграла около $0{,}0020181$ |
| Локализация | Жорданов блок и нормальный контроль, $\varepsilon=0{,}01$ | Радиусы псевдоспектров $0{,}100498756$ и $0{,}01$ |
| Лидский | Эрмитовы матрицы из РС08 | Частичные суммы $(\sqrt2,2,1)$ и $(2,2,1)$ |

| Интерполяция | $uv^\top$, $u=(1,2)^\top$, $v=(3,1,1)^\top$ | Нормы $9,\sqrt{55},10$. Промежуточная оценка $\sqrt{90}$ |

Некоторые строки используют один расчётный блок, поэтому в сценарии 13 групп проверок. У матрицы Коши значения ниже консервативного порога $48\epsilon_{\rm mach}\sigma_1$ не трактуются как точно измеренные сингулярные числа. В разборе квадратуры показана отдельно алгебраическая погрешность свёртки и отдельно ошибка выбранной сетки.

## Что менять при повторении

1. Увеличьте $n$ у единичной матрицы. Сравните плотность поправки при допуске $1/n$ и число правок при свободной амплитуде.
2. Измените частоту синуса на вырожденную. Проверьте, как ранг реагирует на сетку и почему доказанная верхняя граница 2 может не достигаться.
3. При фиксированном возмущении уменьшайте спектральный зазор. Сравните главные углы с оценкой через спроецированную невязку и с границей через полную норму.
4. Сравните график по $p$ и по $1/p$. Теорема интерполяции даёт выпуклость логарифма во второй координате.
5. Для выбранной цели по знакам измерьте $\min |m_{ij}|$ отдельно от ошибки Фробениуса. Проверьте самую близкую к порогу клетку.

Вычислительные проверки относятся к точным учебным примерам, поэтому измерений ускорения обучения моделей здесь нет. [[cap-rank-spectrum-map|Карта всех разборов]] связывает строки лаборатории с доказательствами.
