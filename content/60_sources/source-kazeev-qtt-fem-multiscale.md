# Источник для многошкальной ветки

Vladimir Kazeev, Ivan Oseledets, Maxim Rakhuba, Christoph Schwab. **Quantized Tensor FEM for Multiscale Problems: Diffusion Problems in Two and Three Dimensions.** [ETH report 2020-33, редакция февраля 2022](https://www.sam.math.ethz.ch/sam_reports/reports_final/reports2020/2020-33_rev1.pdf). Журнальная запись: Multiscale Modeling & Simulation 20(3), 2022, 893–935, [DOI 10.1137/20M1341659](https://doi.org/10.1137/20M1341659).

Все математические привязки ниже относятся к **ETH PDF с обложкой, 41 страница**. Напечатанная страница на единицу меньше физической. Полное тождество формул с журнальной версией не заявляется.

Главная граница: Theorem 4.12 оценивает приближение $\mathcal U^\varepsilon v_n$, а не автоматически $\nabla u^\varepsilon$. Для одного микромасштаба дополнительная ошибка $C\varepsilon_1^s$ поглощается лишь при $\Lambda\le(s/\widetilde\alpha)\lambda_1$. При фиксированном масштабе эта конструкция доказательства не даёт асимптотической ошибки исходного решения, стремящейся к нулю. Это прямо сказано авторами на PDF с. 25.
