# В. Босс — «Функциональный анализ»

- Серия: «Лекции по математике», том 5.
- Используемое издание: КомКнига, 2005, 214 печатных страниц.
- Локальный файл: 220 PDF-страниц, чистый скан без текстового слоя.
- Публичный режим: библиографическая карточка и номера страниц; PDF не экспортируется.
- Покрытие: [[30_mathematics/functional-analysis/source-map]].

## Роль источника

Учебник задаёт последовательность тем и помогает сохранять мотивацию. Точные формулировки дополнительно сверяются с классическими версиями теорем, поскольку краткое учебное изложение иногда опускает технические условия.

## Правило цитирования

Использовать ключ `boss2005functional` и указывать диапазон страниц в тексте. Длинные цитаты не переносить: материал должен быть самостоятельным конспектом.
